66. Troubleshooting 
Overview 
The Troubleshooting section is intended to help WiseIN users identify and resolve common 
problems they may experience while using the platform. 
It should provide simple troubleshooting steps for common issues involving account access, 
verification, profiles, notifications, messaging, meetings, posts, jobs, subscriptions, and 
other WiseIN features. 
 
1. General Troubleshooting 
When a WiseIN feature is not working as expected, users should first try the following: 
1.​ Refresh the WiseIN page. 
2.​ Check that the internet connection is stable. 
3.​ Log out and log back in. 
4.​ Try the action again. 
5.​ If using a browser, try clearing the browser cache or using another supported browser. 
6.​ If the issue continues, contact Help & Support and provide details about the problem. 
 
2. Login Problems 
Problem: Unable to log in 
Possible steps: 
●​ Verify that the entered login details are correct. 
●​ Check the internet connection. 
●​ Try logging in again. 
●​ If using Google Sign-In, try the Google login option again. 
●​ If the problem continues, contact WiseIN support. 
Problem: Google login shows "Failed to fetch" 

If Google Sign-In displays a "Failed to fetch" error: 
1.​ Check the internet connection. 
2.​ Refresh the page. 
3.​ Try Google Sign-In again. 
4.​ Try another browser if the problem continues. 
5.​ Contact support if the error persists. 
 
3. OTP Problems 
Problem: OTP is not received 
If a user does not receive an OTP: 
1.​ Check whether the entered phone number/email is correct. 
2.​ Wait briefly for the OTP. 
3.​ Request another OTP if the option is available. 
4.​ Check email spam/junk folders when using email verification. 
5.​ Make sure the phone has network connectivity. 
6.​ Contact support if the OTP still does not arrive. 
Example WiseIN Issue 
An OTP issue may prevent users from completing certain actions, such as saving education 
information. 
 
4. Profile Problems 
Problem: Unable to save profile information 
Users should: 
1.​ Check that all required fields are completed. 
2.​ Verify that the entered information is valid. 
3.​ Check whether an OTP or verification step is required. 
4.​ Try saving again. 
5.​ Refresh and retry if the issue continues. 
 

5. Verification Problems 
If a user experiences problems with WiseIN verification: 
●​ Check that the submitted information is correct. 
●​ Ensure uploaded documents/images meet the required requirements. 
●​ Retry the verification process. 
●​ Check whether the verification status has changed. 
●​ Contact support if verification remains unsuccessful. 
 
6. Video Recording Problems 
Problem: "Some error!" after submitting a recorded video 
If the user receives an error after submitting a recorded video: 
1.​ Check the internet connection. 
2.​ Make sure browser camera/microphone permissions are enabled. 
3.​ Try recording again. 
4.​ Refresh the page and retry. 
5.​ Try another supported browser if the problem continues. 
6.​ Report the issue to WiseIN support with a screenshot if necessary. 
 
7. AI Agent Problems 
Problem: AI Agent does not provide complete video guidance 
If the AI Agent's video guidance is incomplete: 
1.​ Retry the AI Agent interaction. 
2.​ Check the internet connection. 
3.​ Refresh the page. 
4.​ Try the process again. 
5.​ Report the issue if the guidance remains incomplete. 
 
8. Notifications 

Problem: Too many email notifications 
If users receive excessive notifications for activities such as likes or messages: 
1.​ Open Settings → Notifications. 
2.​ Review available notification preferences. 
3.​ Adjust notification settings where available. 
4.​ Contact support if unwanted notifications continue. 
 
9. Chat & Messaging 
Problem: Unable to send a message 
Try: 
1.​ Check the internet connection. 
2.​ Refresh the page. 
3.​ Open the conversation again. 
4.​ Try sending the message again. 
5.​ Check whether the recipient has blocked the user or whether another account restriction 
applies. 
6.​ Contact support if the issue persists. 
 
10. Blocking Problems 
Users can manage blocked users through: 
Settings → Blocked 
If a user has previously blocked someone, they can view the blocked-user list and use the 
Unblock option where available. 
 
11. Reporting Problems 
Users can report inappropriate users/content through the available Report option. 
When reporting a user, WiseIN provides a Report User form containing: 

●​ Reason for Report 
●​ Details 
●​ Optional evidence upload 
●​ Cancel 
●​ Submit Report 
Available report reasons shown include: 
●​ Harassment 
●​ Spam 
●​ Inappropriate Content 
●​ Scam/Fraud 
●​ Impersonation 
●​ Violence 
●​ Other 
 
12. Meetings & Video Calls 
If a meeting or video call is not working: 
1.​ Check the internet connection. 
2.​ Check browser camera permissions. 
3.​ Check microphone permissions. 
4.​ Refresh the page. 
5.​ Rejoin the meeting. 
6.​ Try another browser if necessary. 
7.​ Contact support if the problem continues. 
 
13. Posts & Content 
Problem: Unable to create or publish a post 
Users should: 
1.​ Check their internet connection. 
2.​ Verify that the post content is complete. 
3.​ Check uploaded media. 
4.​ Try publishing again. 
5.​ Refresh the page if necessary. 

Users should also make sure their content follows WiseIN's Content Policies and Community 
Guidelines. 
 
14. Jobs 
Problem: Job-related feature is not working 
Users should: 
●​ Refresh the Jobs page. 
●​ Check their internet connection. 
●​ Try opening the job again. 
●​ Verify that required information has been entered. 
●​ Contact support if the issue continues. 
Job listings should also follow WiseIN's requirements for genuine opportunities. 
 
15. Subscriptions & Billing 
For subscription or billing problems: 
1.​ Check the subscription status. 
2.​ Verify payment information. 
3.​ Check whether the payment was completed. 
4.​ Refresh the subscription page. 
5.​ Contact WiseIN support if the payment or subscription status appears incorrect. 
Do not assume a payment was successful solely because the user attempted the transaction; 
the actual payment status should be checked. 
 
16. Account Deactivation 
If a user wants to temporarily stop using WiseIN: 
Settings → Deactivate 
Deactivation is different from deletion because the displayed WiseIN page states that the 
account can be reactivated later. 

 
17. Account Deletion 
If a user wants to permanently remove their account: 
Settings → Delete Account 
The displayed page states that account deletion: 
●​ Permanently removes the account. 
●​ Removes the user's data from WiseIN. 
●​ Cannot be undone. 
Users should therefore distinguish between Deactivate and Delete Account before taking 
action. 
 
18. Logout Problems 
To log out: 
Settings → Log Out 
WiseIN displays a confirmation popup: 
"Logout from your account?" 
The user can select: 
●​ Cancel 
●​ Logout 
If the user clicked Logout accidentally but has not confirmed it yet, they can select Cancel. 
 
19. When to Contact Support 
Users should contact WiseIN support when: 
●​ A feature repeatedly fails. 
●​ Login remains unsuccessful. 
●​ OTP is not received after retrying. 

●​ Verification cannot be completed. 
●​ Payments or subscriptions appear incorrect. 
●​ Video recording repeatedly fails. 
●​ Messages or meetings cannot be used. 
●​ An account-related problem cannot be resolved through normal troubleshooting. 
●​ The same error continues after refreshing and retrying. 
Information to Include in a Support Request 
To help support investigate the issue, users should provide: 
●​ Description of the problem 
●​ Steps taken before the error occurred 
●​ Error message, if any 
●​ Screenshot or evidence when appropriate 
●​ Relevant feature/page where the problem occurred 
 
AI Chatbot Troubleshooting Flow 
The WiseIN chatbot can follow this structure: 
User reports a problem → Identify feature → Ask what happened → Provide relevant 
troubleshooting steps → Ask user to retry → If unresolved, escalate to human support. 
Example 
User: My OTP isn't coming. 
Bot: Please first verify that your phone number or email is correct and check your network 
connection. If you're using email verification, also check your spam or junk folder. You can then 
request another OTP. If you still don't receive it, I can guide you toward contacting WiseIN 
support. 
User: I tried everything and it still doesn't work. 
Bot: Since the issue is still unresolved after the standard troubleshooting steps, this should be 
escalated to WiseIN support. Please provide the affected feature, the error you see, and a 
screenshot if available.
