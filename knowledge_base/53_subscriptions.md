1. FEATURE OVERVIEW 
The Subscriptions section allows WiseIN users to view their current subscription plan, review 
available plans, change their plan, and manage subscription-related information. 
The subscription section is accessible through: 
Settings → Subscriptions 
WiseIN currently displays different subscription options based on the user's account eligibility. 
The observed subscription plans are: 
●​ WiseIN Go 
●​ Premium 
●​ Student Premium 
Plans can be viewed on a Monthly or Annual billing basis where applicable.

FEATURE

●​ Payment information. 
●​ Options to change or cancel a subscription.

17. SUBSCRIPTION TROUBLESHOOTING 
Issue 1 — Subscription page does not load 
Recommended steps 
1.​ Refresh the WiseIN page. 
2.​ Check the internet connection. 
3.​ Open Settings. 
4.​ Select Subscriptions again. 
5.​ If the problem continues, record the error and contact support. 

 
Issue 2 — Plan information appears incorrect 
The user should provide: 
●​ Current plan displayed. 
●​ Expected plan. 
●​ Account information as requested by support. 
●​ Screenshot of the subscription page. 
●​ Any recent plan-change/payment information. 
Do not instruct the user to make another payment until the subscription status has been verified. 
 
Issue 3 — Payment was made but subscription did not 
update 
The AI should collect: 
●​ Selected plan. 
●​ Approximate payment time. 
●​ Payment status. 
●​ Razorpay transaction/payment reference, if available. 
●​ Screenshot or payment confirmation. 
The issue should then be escalated to human support/payment support. 
 
Issue 4 — Change Plan is not working 
The AI should: 
1.​ Ask which plan the user selected. 
2.​ Determine whether the issue occurs before or after payment. 
3.​ Ask whether an error message is displayed. 
4.​ Avoid asking the user to make repeated payments. 
5.​ Escalate if the issue cannot be resolved. 
 

Issue 5 — User wants to cancel but cancellation fails 
The AI should guide the user to: 
Settings → Subscriptions → Cancel subscription 
If cancellation cannot be completed, collect the error information and escalate the issue.

Yes. WiseIN currently displays a Student Premium plan at ₹199 per month. The

Where can I change my plan?

Go to Settings → Subscriptions, then select Change Plan.

I paid but my Premium isn't active. 
AI: 
I can help you troubleshoot that. Please check which plan you selected, whether 
the payment was completed successfully, and whether WiseIN shows an error or 
still displays your previous plan. If the payment was completed but your 
subscription hasn't updated, the issue may require support verification. 
 
19. AI RESPONSE RULES 
The AI SHOULD 
●​ Provide the current documented prices. 
●​ Clearly distinguish between WiseIN Go, Premium, and Student Premium. 
●​ Explain plan features accurately. 
●​ Provide the Settings → Subscriptions navigation path. 
●​ Explain Change Plan and Cancel Subscription based on verified UI. 
●​ Ask for payment details only when necessary for troubleshooting. 
●​ Escalate payment/subscription issues when required. 
The AI SHOULD NOT 
●​ Invent subscription plans. 
●​ Invent annual prices. 
●​ Assume a plan is available to every user. 
●​ Promise refunds. 
●​ Claim a payment was successful without evidence. 
●​ Expose sensitive payment identifiers. 
●​ Claim a subscription was cancelled without confirmation. 
●​ Assume cancellation automatically results in a refund. 
●​ Treat test-account information as universal. 
●​ Use the unrelated annual screenshot as evidence for WiseIN pricing.
