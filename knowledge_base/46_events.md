Feature: Events 
Platform: WiseIN 
 
1. OVERVIEW 
Events are a WiseIN feature for discovering and participating in professional, networking, 
community, and other activities hosted through the platform. 
WiseIN currently includes public events as part of its individual networking experience. 
The Basic plan explicitly lists “Attend public events” / “Join communities & public 
events” as an included feature. Student users are also offered Student Networking 
Events as part of the Student plan.  
WiseIN's official mobile-app page also describes the app as supporting participation in 
“live audio rooms and events.”  
WiseIN's public website provides an actual public event page, demonstrating that events 
can have their own publicly accessible event page and event schedule/calendar.  
 
2. PURPOSE OF EVENTS 
Events are intended to provide opportunities for WiseIN users to participate in activities 
beyond ordinary profile browsing and one-to-one networking. 
Examples of event-related use cases include: 
• 
professional networking  
• 
founder conversations  
• 
community activities  
• 
student networking  
• 
knowledge-sharing sessions  
• 
career-related activities  
• 
online events  

• 
organization-hosted activities  
• 
webinars  
The official WiseIN website describes its broader ecosystem as including events, audio 
rooms, and conversations with verified people.

26. EVENT ENFORCEMENT 

WiseIN's Content Policies describe enforcement depending on the nature and severity of 
violations. 
For minor violations: 
1. Content may be removed with a warning.  
2. A temporary feature restriction may follow.  
3. Repeated violations may lead to account review.  
Serious violations can result in immediate action, including suspension or permanent ban. 
Severe violations include fraud/scams, identity fraud, data theft, threats/extortion, sexual 
content/advances, and posting private information.  
The chatbot should never promise a specific enforcement result.

51. COMMON USER QUESTIONS 
“What are WiseIN Events?” 
Events are scheduled activities on WiseIN that support professional networking, 
community participation, student networking, and other platform interactions. WiseIN 
supports public events and Student Networking Events.  
“Can free users attend events?” 
Yes. WiseIN currently includes public-event access in the Basic plan.  
“What are Student Networking Events?” 
They are part of WiseIN's Student offering, alongside campus communities, mentor 
sessions, and job/internship access.  
“Are all events public?” 
No such universal rule is documented. WiseIN supports public events, while the public 
Founder Conversations example is approval-based. Event participation requirements can 
vary.  
“Can events require approval?” 
Yes. WiseIN's public Founder Conversations event is explicitly described as approval-
based.  
“What does Subscribe mean?” 

Public WiseIN event pages can show a Subscribe action. The exact behavior of that action 
is not fully documented publicly and may depend on the event implementation. 
“Can I report an event?” 
Yes. WiseIN says users can report events that violate its policies. Reports are described as 
confidential and reviewed within 24 hours.  
“Can I record a WiseIN event?” 
Recording requirements depend on the event and the type of session. WiseIN's policies 
require appropriate awareness/consent for recording and prohibit sharing private meeting 
recordings, transcripts, or AI summaries without permission.  
“Can organizations host events?” 
WiseIN's Organization offering explicitly includes Webinar Hosting. The current India-facing 
Organization plan lists a 2.05% fee for webinars with up to 100 participants and asks 
organizations to discuss larger events with WiseIN.

RAG explains what WiseIN Events are and what the documented policies/features 
mean; live event data determines what events actually exist, when they occur, and 
whether a particular user can participate. 
The architecture should therefore be: 
                 USER QUESTION 
                       │ 
                       ▼ 
                Event Intent 
                       │ 
             ┌─────────┴─────────┐ 
             │                   │ 
        Static Question      Current Question 
             │                   │ 
             ▼                   ▼ 
          RAG KB             Live Event API 
             │                   │ 
             └─────────┬─────────┘ 

                       ▼ 
                Authorization 
                       │ 
                       ▼ 
                 Final Answer

“What are public events?” 
→ RAG.

→ Event-specific information + WiseIN privacy/content policies.
