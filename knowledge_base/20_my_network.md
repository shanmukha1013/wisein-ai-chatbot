20. My Network 
20.1 Overview 
My Network is the networking section of WiseIN where users can manage their professional 
connections and discover other members on the platform. It provides tools for viewing existing 
conversations, managing follow requests, checking sent requests, viewing people the user 
follows, and viewing followers. 
The My Network section also displays Recently Joined members, allowing users to discover 
new people on WiseIN and send follow requests. 
 
20.2 Accessing My Network 
Users can access My Network from the main navigation menu on the left side of WiseIN. 
Navigation 
Home → My Network 
When My Network is selected, the user is taken to the networking dashboard. 
The page contains: 
●​ Search bar 
●​ Conversations 
●​ Follow Request 
●​ Request Sent 
●​ Following 
●​ Followers 
●​ Recently Joined users 
 
20.3 Search Users 
At the top of the My Network page, there is a search field labeled: 

Searching for user 
The search functionality allows users to search for other WiseIN members. 
User interaction 
1.​ Open My Network. 
2.​ Click the search field. 
3.​ Enter the name or relevant search information of a user. 
4.​ Search results can be used to find and connect with other members. 
AI Assistant Guidance 
If a user asks: 
"How do I find someone on WiseIN?" 
The AI Assistant can respond: 
Go to My Network and use the search bar at the top of the page to search for the 
user you want to find. 
 
20.4 Conversations 
The Conversations tab displays people with whom the user already has an existing 
connection/conversation. 
The screen can display: 
●​ User profile picture 
●​ User name 
●​ Professional title or description 
●​ Message button 
Example 
A connected user may appear with information such as: 
●​ Name 
●​ Founder / Developer / Coordinator / other professional role 
●​ Organization or professional information 
●​ Message button 

Messaging 
When the Message button is available, the user can use it to start or continue a conversation 
with that person. 
AI Assistant Guidance 
Question: "Where can I see my connections?" 
Answer: 
Open My Network and select the Conversations tab to view people available for 
conversations. 
 
20.5 Follow Request 
The Follow Request tab shows incoming follow requests from other WiseIN users. 
When there are no pending requests, the page displays: 
When someone requests to follow you, they'll appear here. 
This indicates that incoming requests will appear in this section when another user requests to 
follow the account. 
Purpose 
The Follow Request section allows users to manage requests from people who want to follow 
them. 
AI Assistant Guidance 
Question: "Where can I see follow requests?" 
Answer: 
Go to My Network → Follow Request. Incoming follow requests will appear there. 
 
20.6 Request Sent 

The Request Sent tab shows follow requests that the current user has sent to other users. 
When there are no outstanding requests, the page displays: 
When you send a follow request, it'll appear here. 
Purpose 
This section helps users keep track of follow requests they have initiated. 
Example workflow 
1.​ User finds another person. 
2.​ User selects Follow. 
3.​ The request is sent. 
4.​ The request can appear under Request Sent. 
AI Assistant Guidance 
Question: "Where can I see the follow requests I sent?" 
Answer: 
Go to My Network → Request Sent to view follow requests that you have sent. 
 
20.7 Following

The list can contain: 
●​ Profile picture

●​ Organization/professional information 
●​ Message button 
For example, a followed user may be displayed with their professional role and a Message

Purpose 

The Following section allows users to see the people they are currently following and interact

AI Assistant Guidance 
Question: "How do I see who I follow?" 
Answer:

20.8 Followers 
The Followers tab displays people who follow the current user. 
When there are no followers, the page displays: 
People who follow you will appear here. 
Purpose 
The Followers section allows users to see the people who follow their profile. 
AI Assistant Guidance 
Question: "Where can I see my followers?" 
Answer: 
Go to My Network → Followers to view people who follow you.

It displays users who have recently joined WiseIN. 
Each user entry can contain:

●​ Professional field/organization 
●​ Follow button 
Example information visible 
A recently joined user may appear as: 
User Name​

or: 
User Name​

Following a Recently Joined User 
Users can select the Follow button next to a recently joined member. 
This allows them to send a follow request/connect with the person. 
 
20.10 Follow Workflow 
The general follow workflow observed in My Network is: 
Find User → Follow → Request Sent → Connection/Following 
Step 1 — Find a user 
The user can find another member through: 
●​ Search 
●​ Recently Joined 
Step 2 — Follow 
Select the Follow button displayed next to the user. 
Step 3 — Request Sent 

The request can then appear under: 
My Network → Request Sent 
Step 4 — Follow Request 
The other user can receive the request under: 
My Network → Follow Request 
Step 5 — Connection 
Once the relationship is established, the user may appear in the relevant network/conversation 
sections. 
Knowledge-base note: The supplied screens establish the existence of Follow, 
Follow Request, Request Sent, Following, and Followers. The exact accept/reject 
controls for incoming requests are not visible in the supplied screenshots, so the AI 
Assistant should not claim specific button names for those actions unless confirmed 
elsewhere in the WiseIN documentation.

20.13 User Discovery 
My Network provides multiple ways to discover other members. 
Search 
Users can search for a specific person using the search field. 
Recently Joined 
Users can browse members who recently joined WiseIN. 
Follow 
Users can select Follow next to a discovered user. 
This makes My Network both a connection-management and user-discovery area. 
 

20.14 Empty States 
WiseIN provides informational messages when certain network sections do not contain records. 
Follow Request — Empty State 
When someone requests to follow you, they'll appear here. 
Request Sent — Empty State 
When you send a follow request, it'll appear here. 
Followers — Empty State 
People who follow you will appear here. 
These messages help users understand why a section is empty and what activity will cause 
information to appear.

20.16 AI Assistant — Common Questions 
Q1. What is My Network? 

My Network is the WiseIN section for discovering users and managing your 
professional connections, follow requests, followers, and people you follow. 
Q2. How do I search for a user? 
Open My Network and use the search bar at the top to search for a user. 
Q3. Where are incoming follow requests? 
Go to My Network → Follow Request. 
Q4. Where can I see requests I sent? 
Go to My Network → Request Sent. 
Q5. How do I see who I follow? 
Go to My Network → Following. 
Q6. How do I see my followers? 
Go to My Network → Followers. 
Q7. How can I find new users? 
Open My Network and check the Recently Joined section, or use the search bar. 
Q8. How do I follow someone? 
Find the person in My Network and select the Follow button when available. 
Q9. Where can I see people I can message? 
Check the Conversations or Following sections. Users with an available 
Message button can be contacted from there. 
Q10. Why is my Follow Request section empty? 
If there are no incoming follow requests, WiseIN displays an empty-state message 
indicating that requests will appear there when someone requests to follow you. 
Q11. Why is Request Sent empty? 

If you haven't sent any follow requests, the Request Sent section displays an 
empty-state message explaining that sent requests will appear there. 
Q12. Why don't I see any followers? 
If nobody currently follows your account, the Followers section displays an 
empty-state message. 
 
20.17 AI Troubleshooting Scenarios 
Problem: Follow button is missing 
The AI Assistant should first ask the user: 
●​ Are you viewing the correct user? 
●​ Are you already following the person? 
●​ Is a request already pending? 
●​ Is the user visible in Search or Recently Joined? 
If the problem continues, the AI Assistant should guide the user toward Customer Support. 
Problem: Follow request is not visible 
Suggested troubleshooting: 
1.​ Open My Network. 
2.​ Select Request Sent. 
3.​ Check whether the request appears. 
4.​ If it does not appear, verify that the Follow action was successfully completed. 
5.​ If the issue continues, contact WiseIN support. 
Problem: User cannot find another member 
Suggested troubleshooting: 
1.​ Open My Network. 
2.​ Use the search bar. 
3.​ Check the spelling/name entered. 
4.​ Try searching again. 
5.​ If the user still cannot be found, contact support if necessary. 
 

20.18 AI Assistant Boundaries for My 
Network 
The AI Assistant should not invent network functionality that has not been documented. 
For example, unless confirmed elsewhere, the AI should not claim that users can: 
●​ Cancel a sent request 
●​ Reject a follow request 
●​ Remove a follower 
●​ Block someone directly from My Network 
●​ Sort or filter network members 
●​ Export network information 
If a user asks about an undocumented action, the AI should say: 
I don't have confirmed information about that My Network feature yet. I can help you 
with the available networking options or guide you to WiseIN Customer Support.
