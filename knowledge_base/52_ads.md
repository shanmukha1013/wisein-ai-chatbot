1. FEATURE OVERVIEW 
The Ads feature on WiseIN allows advertisements to be displayed within the platform and 
provides users with an entry point for creating or managing their own advertisements. 
The advertising functionality can be observed in two primary areas of the WiseIN web 
application: 
●​ My Ads — available under Settings. 
●​ Ads displayed on the Home feed — where users can view advertisements from 
advertisers. 
The platform also provides a "Post Ads on WiseIN" entry point from the Home feed for users 
who want to advertise on WiseIN. 
 
2. PURPOSE OF ADS 
The Ads feature is designed to allow businesses, products, organizations, or other advertisers 
to promote their offerings to WiseIN users. 
Advertisements can appear alongside normal platform content within the Home experience. 
The advertising interface provides users with: 
●​ Advertisement visibility within the platform. 
●​ A dedicated My Ads section. 
●​ An option to start creating an advertisement. 

●​ Advertisement cards displayed to users. 
●​ A call-to-action that can direct users to an external destination. 
 
3. ADS LOCATIONS 
The current WiseIN interface shows advertising functionality in two main locations. 
A. My Ads 
Navigation: 
WiseIN → Settings → My Ads 
This section is intended for the user's advertisements. 
B. Home Feed Advertisements 
Advertisements can appear on the Home feed alongside other platform content. 
The Home interface contains a dedicated advertisement area on the right side of the feed. 
 
4. MY ADS 
4.1 Accessing My Ads 
Users can access the advertising section through: 
Settings → My Ads 
The My Ads option is available in the Settings navigation panel. 
When selected, the My Ads page opens.

Empty-State Purpose

14. COMMON USER QUESTIONS 

Q1. Where can I find My Ads? 
Go to: 
Settings → My Ads 
 
Q2. How can I advertise on WiseIN? 
You can access the advertising functionality through My Ads in Settings or through the Post 
Ads on WiseIN option available on the Home page. 
 
Q3. I don't have any ads. What should I do? 
Open: 
Settings → My Ads 
If you have not created an advertisement yet, the page will display: 
Create your first advertisement to get started 
 
Q4. Where do advertisements appear on WiseIN? 
Advertisements can appear within the Home experience. 
The current interface shows an advertisement section on the right side of the Home feed. 
 
Q5. What does the Visit button do? 
The Visit button allows the user to access the destination associated with the advertisement. 
 
Q6. What is Aaharam AI? 

In the current testing environment, Aaharam AI is being used as a test advertisement to 
evaluate WiseIN's advertising display. 
It should not be treated as a permanent WiseIN advertising feature or official WiseIN service. 
 
15. ADVERTISEMENT 
TROUBLESHOOTING 
Issue 1 — My Ads page does not load 
Recommended steps 
1.​ Refresh the WiseIN page. 
2.​ Check the internet connection. 
3.​ Open Settings. 
4.​ Select My Ads again. 
5.​ Check whether the page loads correctly. 
If the issue continues, collect the error information and escalate it to Customer Support. 
 
Issue 2 — Advertisement is not appearing on Home 
If an advertisement is expected to appear but is not visible: 
1.​ Refresh the Home page. 
2.​ Check whether other Home content loads correctly. 
3.​ Check whether the advertising area is visible. 
4.​ Verify whether the advertisement has been successfully created/published. 
5.​ If the issue continues, escalate for further investigation. 
The exact advertisement publishing and approval states must be verified before 
providing more specific troubleshooting instructions. 
 
Issue 3 — Visit button does not work 

If the Visit button does not work: 
1.​ Retry the action. 
2.​ Check the internet connection. 
3.​ Verify whether the issue occurs with only one advertisement or multiple advertisements. 
4.​ Record any error displayed. 
5.​ Escalate the issue if it persists. 
 
Issue 4 — Advertisement content appears incorrect 
If an advertisement displays incorrect information: 
●​ Record the advertisement name. 
●​ Capture the displayed content. 
●​ Record the location where the advertisement appeared. 
●​ Take a screenshot if possible. 
●​ Report the issue to the appropriate support/advertising team. 
 
16. AI CUSTOMER SUPPORT GUIDELINES 
The AI Assistant should first determine what the user is asking about. 
Scenario A — User wants to create an advertisement 
The assistant should direct the user to: 
Settings → My Ads 
It can also mention the Post Ads on WiseIN entry point if appropriate. 
 
Scenario B — User wants to see their advertisements 
The assistant should provide: 
Settings → My Ads 
 

Scenario C — User asks about an advertisement they saw 
The assistant should ask for relevant information such as: 
●​ Advertisement name. 
●​ Where it appeared. 
●​ What problem occurred. 
●​ Whether the Visit button worked. 
●​ Screenshot, if available. 
 
Scenario D — User reports an advertising problem 
The assistant should gather enough information to determine whether the problem relates to: 
●​ Advertisement display. 
●​ Advertisement content. 
●​ Advertisement interaction. 
●​ Advertisement destination. 
●​ Advertisement creation. 
●​ Advertisement management. 
 
17. AI RESPONSE RULES 
The AI SHOULD 
●​ Explain where My Ads is located. 
●​ Explain that advertisements can appear on the Home feed. 
●​ Explain the purpose of the Visit button. 
●​ Direct users to Post Ads on WiseIN when relevant. 
●​ Distinguish between advertiser-side functionality and advertisements shown to users. 
●​ Escalate unresolved advertising issues. 
The AI SHOULD NOT 
●​ Claim that an advertisement is officially approved unless that status is documented. 
●​ Claim that Aaharam AI is a permanent WiseIN partner. 
●​ Invent advertisement pricing. 
●​ Invent advertising plans. 
●​ Invent targeting options. 

●​ Invent payment requirements. 
●​ Claim that an advertisement has been approved, rejected, or published without verified 
status. 
●​ Promise advertisement performance or reach. 
●​ Provide undocumented instructions for creating an advertisement.
