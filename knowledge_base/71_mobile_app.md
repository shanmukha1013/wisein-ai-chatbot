71. Mobile App 
Overview 
The Mobile App section documents WiseIN's mobile experience and provides guidance for 
users accessing WiseIN through a mobile device. 
The purpose of this section in the WiseIN knowledge base is to help users understand how 
mobile access relates to the WiseIN platform, troubleshoot common mobile issues, and know 
when to contact support. 
 
71.1 Mobile Access 
WiseIN is available as a mobile application, allowing users to access the platform from a mobile 
device. 
Users can use the mobile experience for activities such as: 
●​ Accessing their account 
●​ Viewing their profile 
●​ Exploring WiseIN 
●​ Connecting with other users 
●​ Messaging 
●​ Viewing posts and content 
●​ Accessing jobs and opportunities 
●​ Participating in communities 
●​ Managing settings 
●​ Managing account-related options 
 
71.2 Account Access on Mobile 
Users can sign in to their WiseIN account through the mobile application using the available 
authentication methods. 
If a user cannot log in, the standard troubleshooting process should be followed: 

1.​ Check the internet connection. 
2.​ Verify the login information. 
3.​ Try signing in again. 
4.​ Restart the application. 
5.​ Check whether an updated version of the application is available. 
6.​ Contact WiseIN support if the issue continues. 
 
71.3 Mobile App Navigation 
The mobile application should provide access to the major WiseIN areas available to the user. 
Depending on the user's account and available features, these may include: 
●​ Home 
●​ Explore 
●​ Waves 
●​ Jobs 
●​ My Network 
●​ Chat 
●​ Meetings 
●​ Profile 
●​ Notifications 
●​ Settings 
The exact navigation arrangement may differ between the mobile application and website. 
 
71.4 Mobile Notifications 
WiseIN may send notifications to users regarding activity on their account. 
Examples include notifications related to: 
●​ Messages 
●​ Likes 
●​ Connections 
●​ Other platform activity 
Users can manage available notification preferences through: 

Settings → Notifications 
If a user receives unwanted or excessive notifications, they should first review their notification 
settings. 
 
71.5 Camera & Microphone Permissions 
Some WiseIN features require access to the mobile device's: 
●​ Camera 
●​ Microphone 
This may be necessary for features involving: 
●​ Video recording 
●​ Video meetings 
●​ Other audio/video functionality 
If a feature cannot access the camera or microphone, the user should check the WiseIN 
application's permissions in the device settings. 
 
71.6 Internet Connection 
WiseIN's mobile features require an active internet connection. 
If a page or feature does not load correctly: 
1.​ Check Wi-Fi or mobile data. 
2.​ Try another network if available. 
3.​ Close and reopen the WiseIN application. 
4.​ Retry the action. 
 
71.7 App Update 

If a WiseIN feature behaves unexpectedly, users should check whether they are running the 
latest available version of the application. 
An outdated application can potentially cause compatibility or functionality issues. 
Important: The available WiseIN documentation does not specify a particular minimum app 
version or supported operating-system version, so the chatbot should not invent those 
requirements. 
 
71.8 Mobile Troubleshooting 
Problem: App is not loading 
Try: 
1.​ Check internet connectivity. 
2.​ Close and reopen the application. 
3.​ Restart the device. 
4.​ Check for an application update. 
5.​ Try again. 
If the issue persists, contact WiseIN support. 
 
Problem: Login is not working 
Try: 
1.​ Verify login details. 
2.​ Check internet connectivity. 
3.​ Retry the login. 
4.​ Restart the application. 
5.​ Try another available login method. 
6.​ Contact support if the problem continues. 
 
Problem: OTP is not received 
Try: 

1.​ Verify the registered phone number/email. 
2.​ Check network connectivity. 
3.​ Wait briefly. 
4.​ Request another OTP if available. 
5.​ Check spam/junk folders when using email. 
6.​ Contact support if the OTP still does not arrive. 
 
Problem: Camera is not working 
Check: 
1.​ WiseIN's camera permission. 
2.​ Device camera access. 
3.​ Whether another application is currently using the camera. 
4.​ Restart the WiseIN application. 
5.​ Retry the feature. 
 
Problem: Microphone is not working 
Check: 
1.​ WiseIN's microphone permission. 
2.​ Device microphone access. 
3.​ Whether another application is using the microphone. 
4.​ Restart WiseIN. 
5.​ Retry the call or recording. 
 
71.9 Video & Meeting Issues 
If a video meeting or recording does not work correctly: 
1.​ Check the internet connection. 
2.​ Check camera permissions. 
3.​ Check microphone permissions. 
4.​ Close and reopen WiseIN. 
5.​ Retry the meeting or recording. 
6.​ Update the application if an update is available. 
7.​ Contact support if the problem continues.

●​ Sign In & Security 
●​ Subscriptions 
●​ Data Privacy 
●​ Scheduled Posts 
●​ Saved Content 
●​ My Ads 
●​ Blocked 
●​ Deactivate 
●​ Delete Account 
●​ Log Out 
 
71.11 Mobile Logout 
Users can log out from: 
Settings → Log Out 
WiseIN displays a confirmation dialog before logout. 
"Logout from your account?" 
Available actions: 
●​ Cancel 
●​ Logout 
 
71.12 Mobile Account Deactivation 

Users can temporarily pause their account through: 
Settings → Deactivate 
The WiseIN deactivation page states that users can temporarily pause their account without 
losing their data and can reactivate it later. 
 
71.13 Mobile Account Deletion 
Users can access: 
Settings → Delete Account 
The displayed WiseIN deletion page states that account deletion: 
●​ Permanently removes the account. 
●​ Removes the user's data from WiseIN. 
●​ Cannot be undone. 
Users should therefore use Deactivate if they only want to temporarily stop using WiseIN. 
 
71.14 Mobile Security 
Users should protect their WiseIN account by: 
●​ Keeping login credentials private. 
●​ Not sharing OTPs. 
●​ Not sharing passwords. 
●​ Using only their own account. 
●​ Reporting suspicious account activity. 
●​ Contacting WiseIN support if unauthorized access is suspected. 
The Terms & Conditions place responsibility on users to protect their account credentials and 
report suspected unauthorized access.

removes your account and data and cannot be undone.

Bot: Use Settings → Deactivate instead. Deactivation temporarily pauses your account without 
losing your data and allows you to reactivate it later.
