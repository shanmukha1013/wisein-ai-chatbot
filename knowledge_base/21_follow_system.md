## Source: 21 (1).pdf

21. Follow System 
21.1 Overview 
The Follow System is the networking mechanism on WiseIN that allows users to build 
professional connections by following other members. 
Users can discover people through My Network, search for users, or browse the Recently 
Joined section. Depending on the user's relationship with another member, WiseIN can display 
options such as Follow, Message, or different network-status sections. 
The Follow System works together with My Network to manage: 
●​ Following other users 
●​ Incoming follow requests 
●​ Sent follow requests 
●​ Following list 
●​ Followers list 
●​ User discovery 
 
21.2 Where to Find the Follow System 
The main location for managing the Follow System is: 
WiseIN → My Network 
The My Network page contains: 
1.​ Conversations 
2.​ Follow Request 
3.​ Request Sent 
4.​ Following 
5.​ Followers 
6.​ Recently Joined 
 

21.3 Finding a User 
Users can find other WiseIN members through the My Network search bar. 
Steps 
1.​ Open WiseIN. 
2.​ Select My Network. 
3.​ Use the search bar labeled "Searching for user". 
4.​ Search for the desired user. 
5.​ Locate the person's profile. 
6.​ Use the available networking action. 
Users can also discover people through the Recently Joined section. 
 
21.4 Following a User 
When a user is available to be followed, WiseIN displays a Follow button. 
Steps 
1.​ Open My Network. 
2.​ Find the person using Search or Recently Joined. 
3.​ Select Follow. 
4.​ The follow request is sent. 
5.​ The request can then appear under Request Sent. 
AI Assistant Response 
User: "How do I follow someone?" 
AI: 
Go to My Network, find the person you want to follow, and select the Follow 
button. 
 
21.5 Request Sent 

After a user sends a follow request, it can be viewed under: 
My Network → Request Sent 
The Request Sent section is used to track follow requests initiated by the current user.

The Follow Request section is used for incoming follow requests. 
Location:

21.11 Follow vs Message 
The Follow System and messaging functionality are related but different. 
Follow 
Used to establish a following/network relationship with another user. 
Message 
Used to communicate with another user when messaging is available. 
In the supplied My Network screens, Message is visible for users in sections such as 
Conversations and Following. 
AI Assistant Response 
User: "Can I message someone I follow?" 
If a Message button is available for that person in My Network, you can select it to 
start or continue a conversation.

21.14 Common Follow System Questions 
Q1. What is the Follow System? 
The Follow System allows WiseIN users to follow other members and manage their 
professional network through My Network. 
Q2. How do I follow someone? 
Go to My Network, find the user, and select Follow. 
Q3. Where can I find users to follow? 
You can search for users using the My Network search bar or browse the Recently 
Joined section. 
Q4. Where can I see my sent follow requests? 
Go to My Network → Request Sent. 
Q5. Where can I see incoming follow requests? 
Go to My Network → Follow Request. 
Q6. Where can I see the people I follow? 
Go to My Network → Following. 
Q7. Where can I see my followers? 
Go to My Network → Followers. 
Q8. Why is my Follow Request section empty? 
It means there are currently no incoming follow requests displayed in that section. 
Q9. Why is Request Sent empty? 
It means there are currently no sent follow requests displayed in that section. 
Q10. Why is my Followers section empty? 
It means there are currently no followers displayed for your account. 

 
21.15 Follow System Troubleshooting 
Problem: Follow button is not visible 
The AI Assistant should guide the user to: 
1.​ Open My Network. 
2.​ Search for the user. 
3.​ Check the user's listing. 
4.​ Check whether a different network action is already displayed. 
5.​ If the issue continues, contact WiseIN Support. 
The AI should not assume the reason why the Follow button is missing unless the reason is 
documented. 
 
Problem: Follow request is not appearing 
Suggested steps: 
1.​ Open My Network. 
2.​ Select Request Sent. 
3.​ Check whether the request appears. 
4.​ If it does not appear, retry the Follow action if available. 
5.​ If the problem continues, contact WiseIN Support. 
 
Problem: Incoming request is not appearing 
Suggested steps: 
1.​ Open My Network. 
2.​ Select Follow Request. 
3.​ Refresh/check the section. 
4.​ If the request is still missing, contact WiseIN Support. 
 

Problem: User cannot find someone 
Suggested steps: 
1.​ Open My Network. 
2.​ Use the search bar. 
3.​ Enter the user's name. 
4.​ Check the search results. 
5.​ If available, check Recently Joined. 
6.​ If the user still cannot be found, contact Support if necessary. 
 
21.16 AI Assistant Safety Rules 
When answering Follow System questions, the AI Assistant should: 
●​ Give instructions based on documented WiseIN functionality. 
●​ Clearly distinguish Following, Followers, Follow Request, and Request Sent. 
●​ Avoid claiming that a request was successfully sent unless the user has confirmed it. 
●​ Avoid inventing buttons or features. 
●​ Avoid exposing another user's private information. 
●​ Escalate unresolved technical problems to Customer Support. 
 
21.17 Undocumented Follow Actions 
The current source material does not confirm the following actions: 
●​ Cancel a sent follow request 
●​ Reject a follow request 
●​ Remove a follower 
●​ Accept a follow request 
●​ Automatically follow back 
●​ Sort followers 
●​ Filter followers 
●​ Export followers 
●​ Bulk follow users 
Therefore, the AI Assistant should not present these as confirmed WiseIN functionality. 

Recommended AI response 
I don't have confirmed information about that Follow System action in the current 
WiseIN documentation. Please check the available options in My Network or 
contact WiseIN Customer Support for assistance.

22. Connections

Connections in WiseIN represent the professional relationships users build with other members 
through the networking system. 
The Connections functionality works together with My Network, Follow System, and 
Conversations to help users discover people, send follow requests, manage their network, and 
communicate with available connections. 
A user's networking journey can involve: 
Discover User → Follow → Follow Request → Connection → Conversation

sections and networking actions. They do not provide a separate screen explicitly 
titled Connections, so this document uses only the connection-related behavior 
supported by the available My Network screens.
