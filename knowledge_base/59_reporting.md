59. Reporting 
Overview 
WiseIN allows users to report other users when they encounter behavior or content that violates 
platform guidelines or creates a safety concern. The reporting feature is available from a user's 
profile through the three-dot menu. 
How to Report a User 
1.​ Open the user's profile. 
2.​ Click the three-dot menu (⋯) in the top-right corner. 
3.​ Select Report User. 
4.​ The Report User dialog will appear. 
5.​ Select a reason for the report. 
6.​ Enter details explaining the issue. 
7.​ Optionally upload supporting evidence. 
8.​ Click Submit Report. 
Report Reasons 
WiseIN currently provides the following reporting categories: 
●​ Harassment – Report abusive, threatening, or unwanted behavior. 
●​ Spam – Report repetitive, unwanted, or promotional content. 
●​ Inappropriate Content – Report content that violates WiseIN's content standards. 
●​ Scam/Fraud – Report suspected scams, fraudulent activity, or deceptive behavior. 
●​ Impersonation – Report someone pretending to be another person or entity. 
●​ Violence – Report content or behavior involving threats or promotion of violence. 
●​ Other – Use when the issue does not fit the available categories. 
Report Details 
The Details field is required when submitting a report. 
Users should provide relevant information about: 
●​ What happened 
●​ What content or behavior caused the concern 
●​ When or where it occurred 

●​ Any other information that can help WiseIN review the report 
The details field supports up to 500 characters. 
Upload Evidence 
Users can optionally provide evidence to support their report. 
●​ Evidence upload is optional. 
●​ Up to 3 images can be uploaded. 
●​ Maximum size: 5 MB per image. 
●​ Users can click the upload area or drag and drop files. 
Examples of useful evidence may include screenshots showing the reported behavior or 
content. 
Submitting a Report 
After selecting a reason and providing the required details, the user can select Submit Report. 
The Cancel button closes the reporting dialog without submitting the report. 
Reporting Flow 
User Profile → ⋯ Menu → Report User → Select Reason → Add Details → Optional 
Evidence → Submit Report 
Related Safety Action 
The same three-dot menu also provides Block User. Blocking prevents further interaction with 
the user according to WiseIN's blocking functionality, while reporting sends the issue for review. 
AI Customer Support Knowledge 
If a user asks "How do I report someone?", the chatbot should respond: 
Open the user's profile and click the three-dot menu (⋯). Select Report User, 
choose the appropriate reason, provide details about the issue, optionally upload up 
to 3 supporting images, and click Submit Report.
