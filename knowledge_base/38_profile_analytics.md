1. PROFILE ANALYTICS — OVERVIEW 
Profile Analytics is the analytics area associated with a WiseIN individual profile. It is 
intended to help users understand activity and engagement associated with their profile 
and professional presence on WiseIN. 
The current WiseIN website explicitly lists Basic Profile Analytics as a feature of the Basic 
plan and Advanced Profile Analytics as a feature of the Premium plan. This establishes 
that WiseIN provides profile analytics and that the analytics capability can differ according 
to the user's subscription level.  
The individual profile UI previously provided for this documentation also shows an 
Analytics Dashboard associated with the profile. The profile area includes a 
Conversations visualization covering the last 7 days, providing an example of profile-
related activity information available to the user. 
Important chatbot rule 
The chatbot must distinguish between: 
• 
Profile Analytics  
• 
Organization Analytics  
• 
Post/content engagement  
• 
Conversation/meeting activity  
• 
General platform usage analytics  
These are related concepts but should not be treated as identical. 
 
2. PURPOSE OF PROFILE ANALYTICS 
Profile Analytics helps a WiseIN user understand how their professional profile is 
performing and how people are engaging with their presence on the platform. 

Typical purposes include: 
• 
Understanding profile activity  
• 
Monitoring profile-related engagement  
• 
Reviewing conversation activity  
• 
Understanding changes in profile visibility or engagement  
• 
Evaluating whether profile information is attracting relevant interactions  
• 
Tracking professional networking activity  
• 
Using profile information and activity to improve networking effectiveness  
The exact analytics available to a particular account depend on the WiseIN product 
version, account type, and subscription level. 
The public WiseIN website currently confirms Basic Profile Analytics for Basic users and 
Advanced Profile Analytics for Premium users, but it does not publicly document the 
complete list of individual analytics metrics.  
Therefore, the chatbot must not invent a fixed list of analytics metrics.

9. PROFILE ANALYTICS VS PROFILE VISIBILITY 
Profile Analytics and profile visibility are different concepts. 
Profile Analytics 
Analytics tells the user about available profile-related activity or engagement. 
Profile Visibility 
Visibility concerns who can discover or view the profile and how the profile appears within 
WiseIN. 

WiseIN's privacy policy states that public profile information such as a user's name, 
professional details, and skills may be visible to other users, subject to privacy settings.  
The privacy policy also states that WiseIN may use profile and activity data to personalize 
the feed, job recommendations, and connection suggestions.  
Therefore, the chatbot should not interpret an analytics metric as proof of how WiseIN's 
recommendation or discovery algorithms rank a particular profile. 
 
10. PROFILE ANALYTICS VS AI DISCOVERY 
WiseIN Premium includes both: 
• 
Advanced Profile Analytics  
• 
AI Discovery in Search  
These are separate capabilities.  
Profile Analytics 
Used to understand profile-related activity. 
AI Discovery in Search 
Used to help users discover relevant people through WiseIN's discovery/search 
experience. 
The chatbot must not state that: 
“Your analytics score determines your AI Discovery ranking.” 
There is currently no public WiseIN documentation establishing such a formula. 
 
11. PROFILE ANALYTICS VS ORGANIZATION ANALYTICS 
WiseIN also provides analytics for organizations. 
The current pricing page lists Company-wide analytics dashboard for the Organization 
plan.  
The current WiseIN homepage describes Organization Analytics as part of the 
Organization offering.  
These should not be confused with Individual Profile Analytics. 

Individual Profile Analytics 
Associated with an individual user's WiseIN profile. 
Organization Analytics 
Associated with a WiseIN Organization and its organizational activities. 
If a user asks about company analytics, the chatbot should route the question to 
Organization Analytics rather than answering from Individual Profile Analytics 
documentation.

13. PRIVACY AND PROFILE ANALYTICS 
Profile Analytics may involve information about activity associated with a user's profile. 
WiseIN's Privacy Policy states that: 
• 
Public profile information may be visible to other users depending on privacy 
settings.  
• 
WiseIN collects usage data to improve its services.  

• 
WiseIN uses profile/activity information for personalization.  
• 
Users can manage certain profile information and privacy settings through their 
account.  
The chatbot should therefore avoid exposing private analytics belonging to another user. 
Security rule 
A user may ask: 
“How many people viewed my friend's profile?” 
The chatbot must not provide another user's private analytics unless an authorized WiseIN 
API explicitly exposes that information to the requesting user.

21. ANALYTICS TROUBLESHOOTING 
Problem: Analytics Dashboard is not visible 
Possible explanations include: 
• 
The feature is not available to the current account.  
• 
The user is viewing a different profile/account type.  
• 
The UI has changed.  
• 
The account or subscription does not currently provide the expected analytics level.  
• 
Temporary application loading issue.  
Recommended response 
Check that you are signed into the correct WiseIN account and open your individual profile. 
If the Analytics Dashboard is still unavailable, check your current plan and try 
refreshing/reloading WiseIN. If the issue continues, contact WiseIN Support through the 
official support/contact channels. 
Do not state that a specific menu path exists unless the current application confirms it. 
 
22. ANALYTICS DATA IS NOT LOADING 
If the dashboard opens but analytics do not load: 
Recommended troubleshooting: 
1. Refresh the page.  
2. Check the internet connection.  
3. Sign out and sign back in.  

4. Try the latest supported browser/app version.  
5. Try again after a short period if the issue appears temporary.  
6. If the problem continues, contact WiseIN support.  
The chatbot should not tell the user that the database, API, or analytics server is down 
unless an authorized monitoring system confirms it. 
 
23. ANALYTICS NUMBER HAS NOT CHANGED 
If a user says: 
“My analytics number has not changed.” 
The chatbot should avoid assuming that the metric is broken. 
Possible explanations include: 
• 
The metric may not update instantly.  
• 
The displayed metric may use a specific reporting period.  
• 
The activity may not qualify for that particular metric.  
• 
The dashboard may require refreshing.  
• 
There may be a temporary synchronization issue.  
The chatbot should use the actual metric name and time period before diagnosing the 
problem. 
 
24. ANALYTICS DISCREPANCIES 
If the user reports: 
“My profile shows one number, but Analytics shows another.” 
The chatbot should explain that different sections may represent different metrics or time 
periods. 
For example, a profile's visible Followers count is not necessarily the same thing as a 
profile analytics metric. 

The chatbot should ask the user to identify the exact labels shown if the discrepancy 
cannot be resolved from the available documentation.

27. EXAMPLE GOLDEN ANSWERS 
Q: What is Profile Analytics? 
Profile Analytics is the analytics area associated with your WiseIN individual profile. It 
helps you review profile-related activity and engagement available to your account. WiseIN 
currently provides Basic Profile Analytics on the Basic plan and Advanced Profile Analytics 
on Premium. 
Q: Does WiseIN provide Profile Analytics? 

Yes. WiseIN currently lists Basic Profile Analytics as a Basic-plan feature and Advanced 
Profile Analytics as a Premium feature.  
Q: What is Advanced Profile Analytics? 
Advanced Profile Analytics is the expanded profile analytics capability included with 
WiseIN Premium. WiseIN publicly confirms the feature but does not currently publish a 
complete list of all individual metrics included in the advanced dashboard. 
Q: Can I see my current analytics through the chatbot? 
If WiseIN provides an authorized analytics API for your account, the chatbot can retrieve 
current analytics. Without access to live account data, the chatbot can explain the 
analytics feature but should not invent your current numbers. 
Q: Can the chatbot tell me how many profile views I have? 
Only if the current WiseIN account API provides that metric. The knowledge base should 
not invent profile-view numbers or assume that another analytics metric represents profile 
views. 
Q: Why can't I see Advanced Profile Analytics? 
WiseIN currently lists Advanced Profile Analytics as a Premium feature. Basic users have 
Basic Profile Analytics. Check your current plan and the analytics options available on your 
profile.  
Q: Does analytics guarantee more profile visibility? 
No specific visibility increase should be assumed. Analytics provides information about 
available profile activity; it should not be presented as a guarantee of higher visibility, 
followers, conversations, or opportunities.

• 
Authorize access to the requested analytics.  
•

information about profile-related activity and engagement.

• 
Basic Profile Analytics is included in the Basic plan.

Advanced Profile Analytics is included in Premium.

documented on the public WiseIN website currently reviewed. Therefore, the chatbot

names, calculations, time periods, refresh behavior, and current values.

Explain analytics from RAG; retrieve analytics numbers from authorized live data; 
never invent metrics or user-specific values.
