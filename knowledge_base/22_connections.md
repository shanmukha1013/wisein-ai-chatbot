22. Connections 
22.1 Overview 
Connections in WiseIN represent the professional relationships users build with other members 
through the networking system. 
The Connections functionality works together with My Network, Follow System, and 
Conversations to help users discover people, send follow requests, manage their network, and 
communicate with available connections. 
A user's networking journey can involve: 
Discover User → Follow → Follow Request → Connection → Conversation 
Documentation note: The supplied WiseIN screens clearly show the My Network 
sections and networking actions. They do not provide a separate screen explicitly 
titled Connections, so this document uses only the connection-related behavior 
supported by the available My Network screens. 
 
22.2 Accessing Connections 
The main area for managing connections is: 
WiseIN → My Network 
The My Network page provides the following connection-related sections: 
●​ Conversations 
●​ Follow Request 
●​ Request Sent 
●​ Following 
●​ Followers 
●​ Recently Joined 
 

22.3 Discovering People 
Users can discover potential connections through: 
1. Search 
The My Network page contains a search bar labeled: 
Searching for user 
Users can search for other WiseIN members. 
2. Recently Joined 
The Recently Joined section displays users who have recently joined WiseIN. 
Each listed user can include: 
●​ Profile picture 
●​ Name 
●​ Professional title 
●​ Professional field/organization 
●​ Follow button 
 
22.4 Creating a Connection 
A user can initiate a networking relationship by selecting Follow on another user's profile/listing. 
Basic workflow 
1.​ Open My Network. 
2.​ Search for a user or browse Recently Joined. 
3.​ Find the desired user. 
4.​ Select Follow. 
5.​ The request is represented under Request Sent. 
The exact acceptance/confirmation behavior is not shown in the supplied screens, so the AI 
Assistant should not invent the exact next button or status unless it is documented elsewhere. 
 

22.5 Connection Requests 
Connection requests are represented through the Follow System. 
There are two relevant sections: 
Follow Request 
Used for incoming requests from other users. 
Navigation: 
My Network → Follow Request 
Empty state: 
When someone requests to follow you, they'll appear here. 
Request Sent 
Used for requests initiated by the current user. 
Navigation: 
My Network → Request Sent 
Empty state: 
When you send a follow request, it'll appear here.

Navigation: 
My Network → Following

●​ Message button, where available

22.7 Followers 
The Followers section shows people who follow the current user. 
Navigation: 
My Network → Followers

22.8 Conversations 
The Conversations section provides access to users with whom the current account can 
communicate. 
A conversation entry can display: 
●​ Profile picture 
●​ User name 
●​ Professional title/description 
●​ Message button 
Example 
A user may appear with: 

Founder at Sanshi Network Tech private limited @ 1-1 connecting platform 
and a Message button. 
Another user may appear with: 
AI Developer Intern At WiseIN @ IT 
and a Message button. 
 
22.9 Messaging a Connection 
When a Message button is available, users can select it to communicate with that person. 
Steps 
1.​ Open My Network. 
2.​ Open Conversations or another section where the Message button is available. 
3.​ Find the person. 
4.​ Select Message. 
AI Assistant response 
User: "How do I message my connection?" 
Go to My Network, find the person in a section where the Message button is 
available, and select Message.

22.13 Connections vs Following 
The terms should be handled carefully in the AI knowledge base. 
Following 
Refers specifically to people the current user follows. 
Followers 
Refers to people who follow the current user. 
Connections 
Can be used as a general term for the user's professional network, but the supplied WiseIN 
screens do not establish a separate Connections tab or a specific connection-status definition. 
Therefore, when a user asks about "connections," the AI should guide them to My Network and 
the relevant section rather than claiming that a separate Connections page exists.

22.15 Common Questions 
Q1. What are Connections on WiseIN? 
Connections refer to the professional relationships you build with other WiseIN 
members through the networking system. You can manage these relationships 
through My Network. 
Q2. Where can I find my connections? 
Open My Network and check Conversations, Following, and Followers 
depending on the relationship you want to view. 
Q3. How do I connect with someone? 
Find the person through My Network Search or Recently Joined, then select 
Follow when available. 
Q4. Where can I see people I follow? 

Go to My Network → Following. 
Q5. Where can I see people following me? 
Go to My Network → Followers. 
Q6. Where can I see my incoming requests? 
Go to My Network → Follow Request. 
Q7. Where can I see requests I have sent? 
Go to My Network → Request Sent. 
Q8. How do I discover new people? 
Use the search bar in My Network or browse the Recently Joined section. 
Q9. How do I message someone? 
Find the person in a section where the Message button is available and select 
Message. 
Q10. Why can't I find someone in my network? 
Try searching for the user using the My Network search bar. You can also check 
Recently Joined if you're looking for a newly registered member. 
 
22.16 Connection Troubleshooting 
Problem: User cannot follow someone 
Recommended steps: 
1.​ Open My Network. 
2.​ Search for the person. 
3.​ Check whether the Follow button is available. 
4.​ Check whether the person already appears under another network status. 
5.​ If the issue continues, contact WiseIN Support. 
 

Problem: Sent request is not visible 
1.​ Open My Network. 
2.​ Select Request Sent. 
3.​ Check whether the request appears. 
4.​ If it does not appear, retry the action if the Follow button is available. 
5.​ If the issue continues, contact Support. 
 
Problem: Incoming request is missing 
1.​ Open My Network. 
2.​ Select Follow Request. 
3.​ Check the available requests. 
4.​ If the expected request is still missing, contact WiseIN Support. 
 
Problem: Message button is unavailable 
The supplied documentation does not specify every condition that determines when the 
Message button appears. 
The AI should therefore avoid claiming a specific reason unless that behavior is documented. 
Recommended response: 
The Message option is only shown where messaging is available. If you believe it 
should be available but isn't, please contact WiseIN Support.
