# Content Policies

## Source: 61.pdf

61. Content Policies — WiseIN 
Purpose:​
 WiseIN’s Content Policies define the types of content and behavior that are acceptable on the 
platform and help maintain a professional, authentic, and respectful community. 
WiseIN publicly lists Community Guidelines and Content Policies as resources for users. 
 
61.1 What Are Content Policies? 
Content Policies explain what users can and cannot publish, share, upload, or communicate 
through WiseIN. 
They apply to content and interactions across WiseIN, including: 
●​ Profiles 
●​ Posts 
●​ Waves 
●​ Clips 
●​ Communities 
●​ Events 
●​ Conversations 
●​ Video calls 
●​ Comments or other user-generated content 
●​ Job-related content 
●​ Organization-related content 
●​ Shared media and images 
●​ Other interactions available on the platform 
WiseIN positions itself as a verified professional network focused on authentic human 
connections and professional conversations. 
 
61.2 Main Purpose of the Policy 
The Content Policies are intended to: 
1.​ Maintain a safe platform. 

2.​ Encourage professional communication. 
3.​ Protect users from harmful or abusive content. 
4.​ Reduce spam and unwanted interactions. 
5.​ Prevent fraudulent or deceptive activity. 
6.​ Protect users from inappropriate content. 
7.​ Maintain trust between verified members. 
8.​ Support authentic professional networking. 
9.​ Provide users with mechanisms to report problematic content or users. 
 
61.3 Content Users Should Not Post 
Users should not use WiseIN to publish or distribute content that violates applicable laws, harms 
other users, or undermines the professional nature of the platform. 
A. Harassment 
Content or behavior intended to intimidate, threaten, repeatedly target, or harass another user 
should not be posted. 
Examples include: 
●​ Repeated unwanted contact 
●​ Personal attacks 
●​ Threatening messages 
●​ Targeted abuse 
●​ Intimidation 
●​ Bullying 
WiseIN's reporting interface explicitly includes Harassment as a report category. 
 
B. Spam 
Users should not use WiseIN for repetitive or unwanted promotional activity. 
Examples may include: 
●​ Repeated unsolicited messages 
●​ Repeated promotional posts 
●​ Excessive advertising 
●​ Automated or repetitive interactions 

●​ Posting the same content repeatedly 
●​ Sending unwanted promotional material 
Report category available: Spam 
 
C. Inappropriate Content 
Content that is inappropriate for a professional networking environment should not be shared. 
This can include content that is: 
●​ Offensive 
●​ Sexually inappropriate 
●​ Explicit 
●​ Abusive 
●​ Disturbing 
●​ Unsuitable for a professional community 
Report category available: Inappropriate Content 
 
D. Scam / Fraud 
WiseIN should not be used to deceive users or conduct fraudulent activity. 
Examples include: 
●​ Fake offers 
●​ Fraudulent job opportunities 
●​ Fake investment opportunities 
●​ Requests intended to steal money 
●​ Misleading professional claims 
●​ Fraudulent services 
●​ Phishing attempts 
●​ Fake identities or credentials used for deception 
Report category available: Scam/Fraud 
 
E. Impersonation 
Users should not pretend to be another individual, organization, or professional. 

Examples: 
●​ Using another person's identity 
●​ Creating a profile pretending to be someone else 
●​ Misrepresenting an organization 
●​ Using another person's photographs or information deceptively 
●​ Claiming credentials that belong to another person 
Report category available: Impersonation 
This is particularly relevant to WiseIN because the platform emphasizes identity verification and 
authentic professional identities. WiseIN describes its network as one in which members are 
verified through government-backed identity mechanisms. 
 
F. Violence 
Content that promotes, threatens, encourages, or facilitates violence should not be posted. 
Examples can include: 
●​ Threats of physical harm 
●​ Encouraging violence against another person 
●​ Violent threats 
●​ Content intended to facilitate violent activity 
Report category available: Violence 
 
G. Other Violations 
If a user encounters problematic content that does not fit the available categories, WiseIN 
provides an Other reporting option. 
The user can explain the issue through the report details field. 
 
61.4 User Reporting System 
WiseIN provides a Report User function. 

From a user's profile, the three-dot menu provides: 
●​ Block User 
●​ Report User 
The reporting interface contains: 
Required fields 
Reason for Report * 
Users must select a reason. 
Available options shown in the WiseIN interface: 
1.​ Harassment 
2.​ Spam 
3.​ Inappropriate Content 
4.​ Scam/Fraud 
5.​ Impersonation 
6.​ Violence 
7.​ Other 
Details * 
The user must provide information explaining the issue. 
The interface displays a 500-character limit for the details field. 
Optional Evidence 
Users can upload evidence supporting their report. 
The interface states: 
●​ Up to 3 images 
●​ Maximum 5 MB per image 
Actions 
The report form provides: 
●​ Cancel 
●​ Submit Report 
 

61.5 Content Moderation and Reports 
When a user encounters content or behavior that may violate WiseIN's policies, they can report 
it rather than engaging with the offending user. 
A typical reporting flow is: 
User encounters problematic behavior 
↓ 
Open relevant profile/content 
↓ 
Select three-dot menu 
↓ 
Choose Report User 
↓ 
Select reason 
↓ 
Provide details 
↓ 
Optionally upload evidence 
↓ 
Submit Report 
 
61.6 Blocking vs Reporting 
WiseIN provides both Block User and Report User, but they serve different purposes. 
Block User 

Blocking is intended to control the user's own interactions. 
The WiseIN Blocked Users page states that blocked users: 
●​ Cannot message the user 
●​ Cannot call the user 
●​ Cannot see the user's activity 
The user can also unblock them later. 
Report User 
Reporting is used when a user believes another user has violated WiseIN's rules or engaged in 
problematic behavior. 
A report allows the user to: 
●​ Select a violation category 
●​ Explain the problem 
●​ Provide supporting evidence 
 
61.7 Professional and Authentic Use 
WiseIN describes itself as a verified professional network designed around authentic human 
connections. Its public product information emphasizes verified individuals, professional 
networking, conversations, jobs, communities, and opportunities. 
Therefore, users are expected to use the platform in ways consistent with: 
●​ Professional networking 
●​ Authentic identity 
●​ Respectful communication 
●​ Genuine conversations 
●​ Legitimate professional opportunities 
●​ Appropriate content sharing 
 
61.8 Identity and Trust 
Identity authenticity is an important part of WiseIN's platform model. 

WiseIN publicly states that members are verified using government-backed identity mechanisms 
such as Aadhaar, PAN, or DigiLocker, depending on the applicable verification process. 
Content or activity that deliberately misrepresents a person's identity can therefore conflict with 
the platform's trust model.

61.10 How Users Can Report an Issue 
Step 1 
Open the relevant user's profile. 
Step 2 
Click the three-dot menu. 
Step 3 
Select Report User. 

Step 4 
Select the appropriate reason. 
Step 5 
Enter details describing the issue. 
Step 6 
Upload evidence if necessary. 
Step 7 
Click Submit Report. 
 
61.11 Information for WiseIN AI Customer 
Support 
The chatbot should be able to answer questions such as: 
User: "How do I report someone?" 
Answer:​
 Open the user's profile, select the three-dot menu, choose Report User, select the reason, 
provide details, optionally upload evidence, and submit the report. 
 
User: "What reasons can I report someone for?" 
Answer:​
 WiseIN's reporting form currently provides these reasons: Harassment, Spam, Inappropriate 
Content, Scam/Fraud, Impersonation, Violence, and Other. 
 
User: "How many screenshots can I upload?" 
Answer:​
 The reporting form allows up to 3 images, with a maximum size of 5 MB per image. 

 
User: "How long can my report description be?" 
Answer:​
 The report details field has a 500-character limit. 
 
User: "What's the difference between blocking and reporting?" 
Answer:​
 Blocking controls your interaction with another user. Reporting is used to notify WiseIN about 
potentially inappropriate or policy-violating behavior. 
 
61.12 Important Knowledge-Base Note 
For the chatbot, do not invent additional prohibited-content categories or moderation 
penalties unless WiseIN's official Content Policies explicitly document them. 
The material currently available supports the reporting categories above, but it does not provide 
details about: 
●​ Warning systems 
●​ Temporary suspensions 
●​ Permanent bans 
●​ Appeal procedures 
●​ Automated moderation 
●​ Content removal timelines 
●​ Strike systems 
●​ Specific enforcement thresholds 
●​ Exact review procedures 
Those should be added to the knowledge base only after they are confirmed from WiseIN's 
official Content Policies or internal documentation.
