1. OVERVIEW — POSTS ON WISEIN 
1.1 What is a Post? 
A post is user-created content published on WiseIN to share professional, educational, 
technical, career, community, or informational content with the network. 
WiseIN's current platform supports posting updates, Clips, and articles. The Home Feed 
is described by WiseIN as a place for updates and events.  
Posts can be used to share: 
• 
Projects  
• 
Work and professional updates  
• 
Technical knowledge  
• 
Lessons learned  
• 
Questions  
• 
Career experiences  
• 
Achievements  
• 
Events  
• 
Genuine opportunities  
• 
Jobs or internships  
• 
Useful information  
• 
Professional announcements  
• 
Community discussions

7. HOW TO CREATE A POST 
The current WiseIN Home page provides a New Post entry point.  
When the current interface provides the post creator: 
1. Open WiseIN.  
2. Go to Home.  
3. Select New Post or the equivalent post-creation control shown by the current 
interface.  
4. Enter the content of the post.  
5. Select an appropriate category/intent if the interface requests one.  
6. Add supported media or attachments if required.  
7. Review the content.  
8. Publish the post using the available publish control.  
Important AI rule 
Do not tell users that the button is definitely called "Start a Post" or "Publish Post" unless 
that exact label is confirmed in the current product interface. 

The current public Home page confirms "New Post", so that is the safer current 
terminology.  
 
8. BEFORE PUBLISHING A POST 
Before publishing, users should check: 
• 
Is the information accurate?  
• 
Is the content relevant?  
• 
Am I sharing something I created or have permission to use?  
• 
Am I exposing another person's private information?  
• 
Is the post respectful?  
• 
If it is a job or opportunity, is it genuine?  
• 
Have I clearly disclosed important conditions?  
• 
Does the post comply with WiseIN Content Policies?  
• 
Does the selected category accurately describe the post?  
 
9. JOB, INTERNSHIP AND OPPORTUNITY POSTS 
WiseIN has specific rules for jobs, gigs, internships, and other opportunities. 
Every opportunity posted on WiseIN must be genuine. 
A legitimate opportunity should have: 
• 
A real role  
• 
A real organization/company  
• 
Genuine compensation or clearly stated compensation conditions  
Users must be honest if an opportunity is: 
• 
Unpaid  
• 
Equity-only  
• 
Part-time  

• 
Otherwise subject to special conditions  
WiseIN prohibits fake jobs designed to collect user information or generate leads. It also 
prohibits scams, MLM schemes, pyramid schemes, and pay-to-get-a-job offers.  
Chatbot response rule 
If a user asks: 
"Can I post an internship?" 
Answer: 
Yes, if it is a genuine opportunity and complies with WiseIN's content policies. Clearly 
state important conditions such as whether it is paid, unpaid, part-time, or equity-
only.

32. POST NOT VISIBLE AFTER PUBLISHING 
If a user says: 
"I published my post but I can't see it." 
Possible explanations include: 
• 
Feed filtering  
• 
The content being outside the currently displayed feed scope  
• 
The post not loading correctly  

• 
Temporary network/service issues  
• 
Content moderation or removal  
• 
Account/content visibility restrictions  
• 
Product/UI changes  
Recommended troubleshooting 
1. Refresh the Home page.  
2. Check whether a feed filter is active.  
3. Check the user's own profile/activity area if available.  
4. Confirm that the post was actually submitted successfully.  
5. Retry after checking the network connection.  
6. If the issue continues, contact WiseIN Support.  
The current Home page itself can display a "Failed to load posts" state, so the chatbot 
should recognize that temporary post-loading failures can occur.  
 
33. POST CREATION IS NOT WORKING 
If a user cannot create a post: 
Step 1 — Check account status 
Confirm that the user is properly signed in and that the account has the necessary 
permissions/features. 
Step 2 — Check the post composer 
Make sure: 
• 
Required content has been entered.  
• 
Any required category has been selected.  
• 
Attachments are supported by the current uploader.  
Step 3 — Check the connection 
Retry with a stable internet connection. 
Step 4 — Refresh 

Reload the Home page and try again. 
Step 5 — Check account/plan availability 
Posting capabilities can depend on current WiseIN account and subscription 
configuration. WiseIN's current pricing page lists unlimited articles, Clips, and waves under 
Premium, while the India-facing homepage lists post/Clip publishing under Premium.  
Step 6 — Contact support 
If the problem persists, contact WiseIN through the official support/contact channels. 
 
34. MEDIA UPLOAD FAILURE 
If an image, video, or document cannot be uploaded: 
1. Check the file type accepted by the current uploader.  
2. Check the file size shown by the current interface.  
3. Try a smaller/compressed file if appropriate.  
4. Check the internet connection.  
5. Refresh the page.  
6. Try the upload again.  
7. If the issue persists, contact WiseIN Support.  
AI restriction 
Never invent an exact file-size limit. 
The previous reference specifies 10 MB images, 100 MB videos, and 25 MB PDFs, but these 
values are not currently confirmed by the public WiseIN pages used for this verified

36. POST VISIBILITY 
The chatbot must distinguish between: 
Content visibility 
Whether a post can be displayed to users. 
Feed distribution 
Where and when a post may appear within the feed. 
Moderation status 
Whether WiseIN has restricted or removed content. 
These are different concepts. 
The chatbot must not say: 
"Your post is definitely hidden." 
or 
"WiseIN's algorithm has shadow-banned your post." 
unless an authorized WiseIN system explicitly provides that information.

Avoid harmful or illegal content, hate speech, discrimination, sexually explicit material,
