58. Blocking 
58.1 Overview 
WiseIN allows users to block other users when they do not want to interact with them. 
Blocking is designed to give users control over their interactions and prevent unwanted 
communication or activity from a specific account. 
 
58.2 Accessing Blocked Users 
Blocked users can be managed from the Settings section. 
Navigation Path: 
Settings → Blocked 
The Blocked Users page displays users who have been blocked from the account. 
 
58.3 What Happens When a User Is Blocked? 
According to the WiseIN interface, a blocked user: 
●​ Cannot message you. 
●​ Cannot call you. 
●​ Cannot see your activity. 
●​ Cannot interact with you through the restricted communication channels. 
●​ Remains listed under Blocked Users until you unblock them. 
The Blocked Users page specifically states that blocked users will not be able to message, call, 
or see your activity. 
 
58.4 How to Block a User 
A user can be blocked directly from another user's profile. 

Steps 
1.​ Open the user's profile. 
2.​ Select the three-dot menu (⋯). 
3.​ Select Block User. 
4.​ Confirm the blocking action if WiseIN displays a confirmation prompt. 
5.​ The user is added to your Blocked Users list. 
Example 
Profile → ⋯ → Block User 
 
58.5 Block User Option 
The profile menu provides a dedicated Block User option. 
The blocking option is represented with a prohibited/block icon and is separate from Report 
User. 
This allows users to either: 
●​ Block a user to restrict interaction, or 
●​ Report a user when they believe the user or their behavior violates WiseIN policies. 
 
58.6 Viewing Blocked Users 
To view previously blocked users: 
Settings → Blocked 
The page displays: 
●​ User profile picture 
●​ User name 
●​ Username 
●​ Unblock button 
Example: 
Blocked Users​
 Control your conversations. Block users you don't want to interact with. 

 
58.7 Unblocking a User 
Users can reverse a blocking action at any time. 
Steps 
1.​ Open Settings. 
2.​ Select Blocked. 
3.​ Find the user you want to unblock. 
4.​ Select Unblock. 
5.​ The user is removed from the blocked list. 
The WiseIN interface explicitly provides an Unblock button for each blocked account. 
 
58.8 Block vs. Report 
Blocking and reporting serve different purposes. 
Action 
Purpose 
Block User 
Prevent unwanted interaction with a specific user 
Report User Notify WiseIN about potentially inappropriate or policy-violating behavior 
A user may block someone without reporting them, or report someone without blocking them. 
 
58.9 Common User Questions 
Q1. How do I block someone on WiseIN? 
Open their profile → select ⋯ → select Block User. 
Q2. Where can I see people I blocked? 
Go to: 
Settings → Blocked 

Q3. Can I unblock someone? 
Yes. Open Settings → Blocked and select Unblock next to the user. 
Q4. Can a blocked user message me? 
According to the WiseIN interface, blocked users cannot message you. 
Q5. Can a blocked user call me? 
According to the WiseIN interface, blocked users cannot call you. 
Q6. Can a blocked user see my activity? 
According to the WiseIN interface, blocked users cannot see your activity. 
Q7. Does blocking automatically report the user? 
No. Block User and Report User are separate options. 
Q8. I don't want someone contacting me. What should I do? 
You can open their profile and use: 
⋯ → Block User 
If the user's behavior also violates WiseIN rules or policies, you can use Report User.

When a user asks about blocking, the AI Assistant should:

58.11 Troubleshooting 
Block option is not visible 
●​ Confirm that you are viewing the correct user's profile. 
●​ Check the ⋯ menu for Block User. 
●​ Refresh the page and try again. 
●​ If the option is still unavailable, contact WiseIN Support. 
User is still able to interact after being blocked 
If a blocked user can still message, call, or otherwise interact with you: 
1.​ Confirm that the correct account was blocked. 
2.​ Check Settings → Blocked. 
3.​ Verify that the user appears in the blocked list. 
4.​ Document the behavior. 
5.​ Contact WiseIN Support if the issue continues.
