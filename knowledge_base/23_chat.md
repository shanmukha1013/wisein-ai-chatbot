23. Chat 
✦ Overview 
The Chat feature on WiseIN allows users to communicate directly with other verified members 
on the platform. It is designed for professional networking, discussions, collaboration, and 
one-to-one communication. 
Users can start conversations with people in their network and communicate through private 
messages. 
 
✦ 23.1 Accessing Chat 
To access Chat: 
1.​ Log in to your WiseIN account. 
2.​ Open the main navigation menu. 
3.​ Select Chat. 
4.​ The Chat section opens and displays your available conversations. 
5.​ Select a conversation to open the message window. 
Navigation: 
WiseIN → Chat → Select Conversation 
 
✦ 23.2 Starting a Conversation 
Users can start a conversation with another member when messaging is available for that user. 
Steps: 
1.​ Open the person's profile or My Network. 
2.​ Select Message. 
3.​ A chat window opens. 
4.​ Type your message. 
5.​ Send the message. 

The conversation will then appear in the user's Chat section. 
 
✦ 23.3 Chat Conversations 
A conversation represents a private communication between users. 
A chat may contain: 
●​ Text messages 
●​ Previous messages 
●​ Message timestamps 
●​ User information 
●​ Conversation history 
●​ New/unread messages 
●​ Message notifications 
Users can return to an existing conversation from the Chat section. 
 
✦ 23.4 Sending Messages 
To send a message: 
1.​ Open Chat. 
2.​ Select the required conversation. 
3.​ Enter your message in the message field. 
4.​ Review the message. 
5.​ Select Send. 
The message is added to the conversation after successful submission. 
 
✦ 23.5 Receiving Messages 
When another user sends a message: 
1.​ The message appears in the relevant conversation. 
2.​ The conversation may be shown as having a new/unread message. 
3.​ The user can open the conversation to read and respond. 

Depending on notification settings, WiseIN may also notify the user about new messages. 
 
✦ 23.6 Conversation History 
WiseIN maintains the conversation history so users can continue previous discussions. 
When a user opens an existing conversation, previously exchanged messages can be displayed 
in chronological order. 
Conversation history helps users: 
●​ Continue previous discussions 
●​ Review earlier messages 
●​ Understand the context of a conversation 
●​ Refer back to information shared previously 
 
✦ 23.7 Chat Through My Network 
Users can access messaging through My Network. 
For example, the My Network section may display people under: 
●​ Conversations 
●​ Follow Request 
●​ Request Sent 
●​ Following 
●​ Followers 
Users who can be contacted may have a Message button. 
Example flow: 
My Network → Following/Conversations → Select User → Message 
 
✦ 23.8 Message Availability 
The ability to message another member can depend on WiseIN's networking and 
communication rules. 

If the Message option is unavailable, the user should check: 
●​ Whether the users are connected/following each other 
●​ Whether the recipient has restricted communication 
●​ Whether the recipient's account is active 
●​ Whether the user has been blocked 
●​ Whether the platform has temporarily restricted messaging 
 
✦ 23.9 Chat Notifications 
Users may receive notifications when new messages arrive. 
Notifications can help users identify: 
●​ New messages 
●​ New conversations 
●​ Unread conversations 
●​ Other relevant communication activity 
Users can manage available notification preferences through: 
Settings → Notifications 
 
✦ 23.10 Opening a Conversation 
To open an existing conversation: 
1.​ Go to Chat. 
2.​ Locate the required user/conversation. 
3.​ Select the conversation. 
4.​ The conversation window opens. 
5.​ Review previous messages. 
6.​ Send a new message if required. 
 
✦ 23.11 Unread Messages 
Unread conversations should be distinguishable from conversations that have already been 
viewed. 

An unread message generally indicates that the recipient has received a new message that has 
not yet been opened. 
If an unread indicator is available, selecting the conversation should allow the user to review the 
new message. 
 
✦ 23.12 Professional Communication 
WiseIN is a professional networking platform, so users should use Chat responsibly. 
Recommended communication includes: 
●​ Professional introductions 
●​ Networking 
●​ Career discussions 
●​ Collaboration 
●​ Business discussions 
●​ Project discussions 
●​ Job-related communication 
●​ Questions about professional opportunities 
Users should avoid sending unwanted, abusive, threatening, misleading, or spam messages. 
 
✦ 23.13 Spam and Unwanted Messages 
Users should not use Chat to: 
●​ Send repetitive messages 
●​ Mass-message users 
●​ Promote unrelated products or services 
●​ Send malicious links 
●​ Send fraudulent offers 
●​ Harass other users 
●​ Request sensitive personal information without a legitimate reason 
Repeated or abusive messaging may violate WiseIN's platform and content policies. 
 
✦ 23.14 Privacy 

Chat conversations are intended for private communication between the participants. 
Users should avoid sharing sensitive information unnecessarily. 
Do not share: 
●​ Passwords 
●​ OTPs 
●​ Bank details 
●​ Payment credentials 
●​ Government identification documents 
●​ Other people's private information 
●​ Confidential company information 
Users should also avoid publicly sharing screenshots or private conversations without 
appropriate consent. 
 
✦ 23.15 Blocking a User 
If a user does not want to communicate with another member, they may be able to block that 
user through the available blocking controls. 
After blocking, communication and other interactions between the accounts may be restricted 
according to WiseIN's blocking functionality. 
Users can manage blocked accounts through: 
Settings → Blocked 
 
✦ 23.16 Reporting a Chat or User 
If a conversation contains inappropriate or policy-violating content, the user should use the 
available reporting mechanism. 
Examples of reportable behavior include: 
●​ Harassment 
●​ Threats 
●​ Scams 
●​ Spam 
●​ Impersonation 

●​ Fraudulent offers 
●​ Privacy violations 
●​ Inappropriate content 
●​ Malicious links 
If an in-chat reporting option is unavailable, the user can contact WiseIN Customer Support. 
 
✦ 23.17 Chat Safety 
Users should exercise caution when communicating with other members. 
WiseIN verification helps establish that an account belongs to a real person, but users should 
still independently evaluate requests and information received through Chat. 
Never share: 
●​ Login credentials 
●​ OTPs 
●​ Passwords 
●​ Card information 
●​ Banking credentials 
●​ Security codes 
If someone asks you to make a payment or provides a suspicious opportunity, verify the 
information before taking action. 
 
✦ 23.18 Common Chat Problems 
Problem: Cannot send a message 
Possible reasons: 
●​ Recipient cannot currently be contacted. 
●​ User has been blocked. 
●​ Recipient has blocked the sender. 
●​ Account restrictions are active. 
●​ Temporary platform issue. 
●​ Network connection problem. 
Problem: Messages are not loading 

Possible causes: 
●​ Internet connection issue 
●​ Temporary server problem 
●​ Application/browser issue 
●​ Session expiration 
Problem: New message is not appearing 
Try: 
1.​ Refreshing the page. 
2.​ Reopening the conversation. 
3.​ Checking the internet connection. 
4.​ Logging out and signing in again. 
5.​ Checking whether the issue affects other conversations. 
Problem: Notifications are not received 
Check: 
Settings → Notifications 
Also verify browser/device notification permissions and network connectivity. 
 
✦ 23.19 Chat and Customer Support 
The WiseIN Chat feature is intended for communication between platform users. 
It should not be confused with WiseIN Customer Support. 
For platform-related problems such as: 
●​ Login problems 
●​ Account problems 
●​ Bugs 
●​ Payment/subscription issues 
●​ Verification issues 
●​ Technical problems 
users should contact WiseIN Customer Support. 
 

✦ AI Assistant Knowledge 
The WiseIN AI Assistant should be able to answer questions such as: 
Q: How do I chat with someone on WiseIN?​
 A: Open Chat from the main navigation and select an existing conversation. To start a new 
conversation, open the person's profile or My Network and select Message when the option is 
available. 
Q: How do I message someone from My Network?​
 A: Open My Network, find the person you want to contact, and select Message if messaging is 
available. 
Q: Where can I see my previous messages?​
 A: Open Chat and select the relevant conversation to view the available conversation history. 
Q: I cannot send a message. What should I do?​
 A: Check your internet connection and whether messaging is available with that user. If the 
problem continues, refresh the page, sign in again, and contact WiseIN Support if necessary. 
Q: I am receiving unwanted messages.​
 A: You can use the available blocking/reporting options. If the messages involve harassment, 
scams, threats, or other policy violations, report the user or contact WiseIN Customer Support. 
Q: Can I share my OTP through Chat?​
 A: No. Never share OTPs, passwords, banking credentials, or other sensitive security 
information through Chat. 
Q: Can I report inappropriate messages?​
 A: Yes. Use the available reporting option where provided. You can also contact WiseIN 
Customer Support for assistance. 
Q: How do I stop communicating with someone?​
 A: Use the available blocking controls. You can manage blocked users through Settings → 
Blocked. 
 
✦ AI Assistant Response Rules for Chat 
When answering Chat-related questions, the AI Assistant should: 
1.​ Explain the relevant navigation path. 
2.​ Give clear step-by-step instructions. 

3.​ Avoid claiming that a feature exists if it has not been documented. 
4.​ Distinguish between Chat, My Network, and Customer Support. 
5.​ Never ask users to share passwords, OTPs, or other sensitive credentials. 
6.​ Escalate unresolved technical problems to human support. 
7.​ For harassment, threats, scams, or serious safety concerns, recommend reporting and 
contacting WiseIN Support. 
8.​ Use the latest documented WiseIN workflow as the source of truth.
