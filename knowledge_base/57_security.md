57. Security 
57.1 Overview 
WiseIN provides security-related controls to help users protect their accounts, manage sign-in 
activity, and maintain the security of their account. 
Security settings are available under: 
Settings → Sign in & Security 
This section should be used when a user has questions or problems related to account access, 
authentication, OTP verification, or other sign-in security concerns. 
 
57.2 Sign in & Security 
The Sign in & Security section is available from the Settings menu. 
Navigation Path: 
Settings → Sign in & Security 
Users can access this section to manage or review security-related account settings. 
 
57.3 Account Authentication 
WiseIN uses authentication mechanisms to verify that the person attempting to access an 
account is authorized to do so. 
Authentication may involve: 
●​ Registered email verification 
●​ One-Time Password (OTP) 
●​ Google sign-in 
●​ Other authentication methods supported by the platform 
The exact authentication options available may depend on the user's account and the current 
WiseIN implementation. 

 
57.4 OTP Verification 
OTP verification is used during authentication to confirm the user's identity. 
OTP Process 
1.​ Enter the registered email/account details. 
2.​ Request an OTP. 
3.​ WiseIN sends the OTP to the registered email. 
4.​ Enter the received OTP. 
5.​ WiseIN verifies the OTP. 
6.​ If the OTP is valid, authentication can continue. 
OTP Expiry 
The login OTP email currently indicates that the OTP expires after 10 minutes. 
Users should enter the OTP before it expires. 
 
57.5 Invalid OTP 
If an incorrect OTP is entered, WiseIN displays: 
Invalid OTP 
The message appears in red to indicate that the entered OTP could not be verified. 
Recommended User Action 
If the OTP is rejected: 
1.​ Verify that the OTP was entered correctly. 
2.​ Check that the OTP has not expired. 
3.​ Use the latest OTP received. 
4.​ Request a new OTP if necessary. 
5.​ Contact WiseIN Support if the problem continues. 
 

57.6 Unauthorized Login Attempts 
If a user receives an OTP or login-related email without attempting to sign in, they should not 
share the OTP with anyone. 
The authentication email advises users to contact support if the login attempt was unauthorized. 
Security Recommendation 
Users should never provide their: 
●​ OTP 
●​ Password 
●​ Authentication credentials 
●​ Account verification information 
to another person. 
 
57.7 Google Sign-In 
WiseIN may provide Google-based authentication for account access. 
Users can use the available Continue with Google / Google Sign-In option when it is 
presented on the login screen. 
Google Login Error 
A previously observed WiseIN issue was: 
Failed to fetch 
when attempting to log in using Google. 
If this error occurs, the user should retry the login and, if the issue persists, contact WiseIN 
Support. 
 
57.8 Account Security Best Practices 
Users should follow these practices to protect their WiseIN account: 

●​ Never share OTPs with anyone. 
●​ Never share account credentials. 
●​ Use the official WiseIN application or website. 
●​ Do not approve login attempts that the user did not initiate. 
●​ Contact support when suspicious account activity is detected. 
●​ Keep access to the registered email account secure. 
 
57.9 Security & Privacy Relationship 
Security and privacy are related but represent different areas of WiseIN. 
Security focuses on protecting the user's account and authentication. 
Privacy focuses on how user information is collected, handled, shared, and controlled. 
For privacy-related questions, refer to: 
56. Privacy 
For account authentication and sign-in issues, refer to: 
57. Security 
 
57.10 Common Security Support Questions 
Q1. I did not request an OTP. What should I do? 
Do not share the OTP. If the login attempt was not initiated by you, contact WiseIN Support. 
Q2. My OTP says "Invalid OTP." What should I do? 
Check that you entered the latest OTP correctly and that it has not expired. Request a new OTP 
if required. 
Q3. How long is the OTP valid? 
The login OTP email currently states that the OTP expires after 10 minutes. 
Q4. Someone asked me for my WiseIN OTP. Should I give it to them? 

No. OTPs should not be shared with other people. 
Q5. I cannot log in using Google. What should I do? 
Retry the Google login. If the issue continues, contact WiseIN Support and provide the error 
message displayed. 
Q6. Where can I find WiseIN security settings? 
Go to: 
Settings → Sign in & Security 
 
57.11 AI Assistant Response Guidelines 
When a user asks about account security, the WiseIN AI Assistant should: 
1.​ Identify whether the issue is related to authentication, OTP, Google login, or account 
security. 
2.​ Provide the relevant troubleshooting steps. 
3.​ Never ask the user to provide an OTP or password. 
4.​ Never request sensitive authentication credentials. 
5.​ Escalate persistent or suspicious security issues to human support. 
6.​ Clearly distinguish security issues from privacy-related questions. 
 
57.12 Security Escalation 
Security-related issues should be escalated to human support when: 
●​ The user reports unauthorized account access. 
●​ The user receives unexpected OTPs repeatedly. 
●​ Authentication continues to fail after troubleshooting. 
●​ The user reports suspicious account activity. 
●​ The user believes their account has been compromised. 
●​ The issue requires account-level investigation. 
Important: The AI Assistant should provide guidance but should not request or collect the 
user's OTP, password, or other authentication secrets.
