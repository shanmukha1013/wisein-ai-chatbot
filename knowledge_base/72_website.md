72. Website 
Overview 
The Website section documents WiseIN's web-based platform and explains how users can 
access and use WiseIN through a web browser. 
The website provides access to WiseIN's professional networking, communication, content, 
opportunities, meetings, account management, and support features. 
 
72.1 Accessing WiseIN 
Users can access WiseIN through a supported web browser. 
The web platform allows users to: 
●​ Create and access their account 
●​ Complete and manage their profile 
●​ Explore other members and content 
●​ Build professional connections 
●​ Create and interact with posts 
●​ Send messages 
●​ Participate in meetings 
●​ Discover jobs and opportunities 
●​ Join communities 
●​ View events 
●​ Manage subscriptions 
●​ Manage account settings 
●​ Contact customer support 
 
72.2 Website Navigation 
The main areas documented for WiseIN include: 
●​ Home 

●​ Explore 
●​ Waves 
●​ Jobs 
●​ My Network 
●​ Chat 
●​ Meetings 
●​ Analytics 
●​ Organizations 
●​ Profile 
●​ Posts / Feed 
●​ Events 
●​ Subscriptions 
●​ Settings 
The exact navigation and available options may depend on the user's account and the current 
version of WiseIN. 
 
72.3 Browser Access 
WiseIN users should access the website through a modern, supported web browser. 
If a feature does not work correctly, users can try: 
1.​ Refreshing the page. 
2.​ Checking their internet connection. 
3.​ Opening WiseIN again. 
4.​ Trying another supported browser. 
5.​ Clearing browser cache if necessary. 
6.​ Contacting support if the problem continues. 
Important: The available WiseIN documentation does not specify an official list of supported 
browsers or minimum browser versions. The chatbot should not invent one. 
 
72.4 Website Login 
Users can access their WiseIN account through the website using the available login methods. 
If login fails: 

1.​ Verify the entered information. 
2.​ Check the internet connection. 
3.​ Refresh the page. 
4.​ Try logging in again. 
5.​ Try another browser if necessary. 
6.​ Contact support if the problem continues. 
 
72.5 Google Sign-In 
WiseIN supports Google-based login. 
During testing, a "Failed to fetch" error was observed while attempting Google Sign-In. 
If this occurs: 
1.​ Check the internet connection. 
2.​ Refresh the WiseIN website. 
3.​ Try Google Sign-In again. 
4.​ Try another browser. 
5.​ Contact support if the error continues. 
 
72.6 Website Permissions 
Certain WiseIN features may require browser permissions. 
Examples include: 
●​ Camera 
●​ Microphone 
●​ Notifications 
These permissions may be required for features such as: 
●​ Video meetings 
●​ Video recording 
●​ Audio communication 
●​ Browser notifications 

If a feature does not work, users should check whether the relevant browser permission has 
been allowed for WiseIN. 
 
72.7 Video & Meeting Features 
WiseIN's website includes functionality involving meetings and video. 
For video-related problems: 
1.​ Check the internet connection. 
2.​ Check browser camera permissions. 
3.​ Check microphone permissions. 
4.​ Refresh the page. 
5.​ Rejoin the meeting or retry the recording. 
6.​ Try another browser if necessary. 
7.​ Contact support if the issue continues. 
 
72.8 Website Profile Management 
Users can manage their profile through the website. 
Profile-related functionality includes information such as: 
●​ Personal information 
●​ Professional information 
●​ Education 
●​ Profile content 
●​ Other information made available through the profile system 
If profile information cannot be saved: 
1.​ Check required fields. 
2.​ Verify the information entered. 
3.​ Complete any required verification/OTP step. 
4.​ Retry saving. 
5.​ Contact support if the problem persists. 
 

72.9 Website Content 
Users can interact with WiseIN content through the website. 
Depending on the available functionality, users can: 
●​ Create posts 
●​ View posts 
●​ Interact with content 
●​ Save content 
●​ Schedule posts 
●​ Report inappropriate content 
●​ Manage content-related settings 
All content must follow WiseIN's Community Guidelines and Content Policies. 
 
72.10 Jobs & Opportunities 
The WiseIN website provides access to job and opportunity-related features. 
Users may be able to: 
●​ Discover opportunities. 
●​ View job listings. 
●​ Interact with available opportunities. 
●​ Post opportunities where authorized. 
Job listings must comply with WiseIN's content requirements and must represent genuine 
opportunities. 
 
72.11 Messaging & Chat 
The website provides messaging functionality through Chat. 
Users can use Chat to communicate with other WiseIN users. 
If messaging does not work: 

1.​ Check the internet connection. 
2.​ Refresh the page. 
3.​ Reopen the conversation. 
4.​ Try sending the message again. 
5.​ Check whether the relevant account interaction is restricted. 
6.​ Contact support if the problem continues. 
 
72.12 Notifications 
WiseIN provides notifications for relevant account activity. 
If users receive excessive or unwanted notifications, they can review the available notification 
preferences under: 
Settings → Notifications 
If notification behavior continues unexpectedly, the user can report the issue to support. 
 
72.13 Website Settings 
Users can access account and platform settings through the Settings area. 
The documented Settings options include areas such as: 
●​ Profile 
●​ Notifications 
●​ Sign In & Security 
●​ Subscriptions 
●​ Data Privacy 
●​ Scheduled Posts 
●​ Saved Content 
●​ My Ads 
●​ Blocked 
●​ Deactivate 
●​ Delete Account 
●​ Log Out 
 

72.14 Website Account Deactivation 
To temporarily deactivate an account: 
Settings → Deactivate 
The WiseIN deactivation interface states that users can temporarily pause their account without 
losing their data and can reactivate it later. 
 
72.15 Website Account Deletion 
To permanently delete an account: 
Settings → Delete Account 
The WiseIN deletion interface states that: 
●​ The account is permanently removed. 
●​ User data is removed from WiseIN. 
●​ The action cannot be undone. 
Users should therefore carefully distinguish Deactivate from Delete Account. 
 
72.16 Website Logout 
Users can log out through: 
Settings → Log Out 
A confirmation dialog appears: 
"Logout from your account?" 
The user can select: 
●​ Cancel 
●​ Logout 
Selecting Cancel closes the confirmation dialog without logging out. 

 
72.17 Website Security 
Users should protect their WiseIN account by: 
●​ Keeping passwords private. 
●​ Never sharing OTPs or authentication codes. 
●​ Avoiding sharing account credentials. 
●​ Logging out when using a shared/public computer. 
●​ Reporting suspicious activity. 
●​ Contacting support if unauthorized account access is suspected. 
The chatbot should never ask users to provide their password or OTP.

72.21 AI Customer Support — Website 
Questions 
User: How do I access WiseIN on my computer? 
Bot: Open WiseIN in a supported web browser and sign in using your available login method. 
User: WiseIN isn't loading on my browser. 
Bot: Please check your internet connection and refresh the page. If the issue continues, try 
another browser. If you still cannot access WiseIN, contact customer support. 
User: My camera isn't working on WiseIN. 

Bot: Please check whether your browser has permission to access your camera. Also check 
your internet connection and try refreshing the page. 
User: My microphone isn't working. 
Bot: Check your browser's microphone permission for WiseIN, then refresh the page and try 
again. 
User: Can I delete my account from the website? 
Bot: Yes. Go to Settings → Delete Account. Account deletion is permanent and cannot be 
undone. 
User: I don't want to delete my account. I just want to take a break. 
Bot: Use Settings → Deactivate instead. Deactivation temporarily pauses your account and 
allows you to reactivate it later. 
User: I found a bug on the website. 
Bot: You can report it through WiseIN Customer Support by selecting Bug report. Include the 
steps that caused the issue and a screenshot if available. 
 
72.22 Website Knowledge-Base Rules 
The AI assistant should: 
●​ Give website-specific instructions when the user is using the web platform. 
●​ Distinguish website issues from mobile-app issues. 
●​ Use exact WiseIN navigation names. 
●​ Provide troubleshooting before escalation when appropriate. 
●​ Ask for the exact error message when the problem is unclear. 
●​ Avoid inventing browser requirements or technical specifications. 
●​ Escalate issues that cannot be resolved using documented information. 
Standard Flow 
Website problem → Identify feature → Check knowledge base → Provide steps → User 
retries → Resolved? 
Yes → End 

No → Human Escalation
