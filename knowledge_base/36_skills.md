1. SKILLS — OVERVIEW 
The Skills section is a part of the WiseIN individual profile where users can present the 
skills they have. 
In the current WiseIN profile interface previously provided, the profile contains a Key Skills 
section with an edit control and visible skill tags such as: 
• 
Python  
• 
Java  
• 
JavaScript  
• 
Show more  
The Skills section helps users communicate their areas of capability and professional 
expertise as part of their profile. 
WiseIN's current Privacy Policy explicitly identifies skills as profile information that users 
may choose to add to their profile, alongside professional bio, experience, education, 
projects, and social links.  
 
2. PURPOSE OF THE SKILLS SECTION 
The Skills section allows users to communicate their professional or technical capabilities 
to people viewing their WiseIN profile. 
Skills can provide context about: 
• 
Professional expertise  
• 
Technical capabilities  
• 
Areas of interest  

• 
Career specialization  
• 
Practical abilities  
• 
Professional background  
Skills complement other profile information such as: 
• 
About  
• 
Education  
• 
Projects  
• 
Experience  
• 
Website  
• 
Profile Video  
• 
Posts  
• 
Clips  
• 
Sessions  
• 
Webinars  
• 
Slots  
A user's skills should therefore be understood as part of their profile information, not as a 
separate social-media content format. 
 
3. WHERE SKILLS APPEAR 
Skills appear in the individual WiseIN profile. 
In the profile interface previously provided, the section is labelled: 
Key skills 
and includes an edit control. 
The profile can display individual skills as skill tags. 
For example: 
Python 

Java 
JavaScript 
Show more 
The exact skills displayed depend on the information associated with the user's profile. 
 
4. ADDING SKILLS 
Users can add skills through the profile's Skills/Key Skills section when the current 
interface provides the relevant editing functionality. 
General flow: 
1. Open the WiseIN individual profile.  
2. Locate Key Skills.  
3. Select the available edit control.  
4. Add or select the desired skills using the current interface.  
5. Save the changes.  
6. Confirm that the skills appear on the profile.  
The exact input method, field names, search behavior, autocomplete behavior, save 
button, and validation rules should be taken from the current WiseIN application. 
Important chatbot rule 
Do not invent a specific Skills form workflow if the current application has changed.

6. KEY SKILLS 
WiseIN's profile interface uses the label Key Skills. 
The purpose of Key Skills is to highlight relevant capabilities directly on the user's profile. 
If the profile contains more skills than can be displayed in the initial view, the interface may 
provide a “Show more” control, as observed in the current profile UI. 
The chatbot should describe the currently visible UI rather than assuming a fixed display 
limit. 
 
7. SKILLS AND PROFILE DISCOVERY 
Skills are particularly relevant to WiseIN's discovery experience. 
WiseIN's current website explicitly states that users can: 
“Explore a curated list of individuals by skill, industry, and experience.” 
The official WiseIN app page similarly states that users can discover verified 
professionals by skill.  

Therefore, skills are an important part of how users can communicate their professional 
areas within WiseIN's discovery experience. 
Important distinction 
The chatbot should not claim that adding a particular skill guarantees: 
• 
Higher ranking  
• 
More profile views  
• 
More connections  
• 
More calls  
• 
Job offers  
• 
Recruiter attention  
unless WiseIN's internal discovery specification explicitly confirms such behavior. 
 
8. SKILLS AND SEARCH 
WiseIN publicly describes discovery based on skill, industry, and experience.  
This means that a user searching for people based on professional capabilities may 
encounter profiles where skills are relevant to the discovery context. 
For example, a user interested in: 
Python 
may use WiseIN's discovery/search experience to find relevant people. 
The chatbot should not claim a specific search algorithm or ranking formula unless the 
internal WiseIN product/API documentation provides it. 
 
9. SKILLS AND AI DISCOVERY 
The current WiseIN Premium offering includes AI Discovery in Search.  
The public website does not provide the exact algorithm or ranking formula used by AI 
Discovery. 
Therefore, the chatbot should say: 

“WiseIN uses discovery features to help users find relevant people based on profile 
information such as skills, industry, and experience.” 
It should not claim: 
“Your skill appears first because WiseIN gives it a higher ranking.” 
unless that behavior is documented internally. 
 
10. SKILLS AND PROFILE VISIBILITY 
Skills are part of profile information. 
WiseIN's Privacy Policy states that public profile information can include skills and that 
visibility depends on the user's privacy settings.  
Therefore, the chatbot should explain: 
“Your skills are part of your profile information. Their visibility depends on the profile and 
privacy settings available on your WiseIN account.” 
Do not promise that skills are: 
• 
Always public  
• 
Always private  
• 
Visible only to connections  
• 
Visible only to verified users  
unless the current application explicitly confirms the behavior. 
 
11. EDITING SKILLS 
If a user wants to change their skills: 
1. Open the WiseIN profile.  
2. Locate Key Skills.  
3. Use the available edit control.  
4. Add, remove, or modify skills using the current interface.  
5. Save the changes.  

The exact UI labels should follow the current application. 
If the user does not see an edit control, the chatbot should not invent a hidden menu or 
alternate route. 
 
12. REMOVING A SKILL 
If the current Skills editor provides a remove/delete option, the user can remove the skill 
from the profile. 
General flow: 
1. Open the profile.  
2. Go to Key Skills.  
3. Open the available editing interface.  
4. Locate the unwanted skill.  
5. Remove it.  
6. Save the changes.  
WiseIN's Privacy Policy states that users can edit or delete certain profile information 
through their account settings.

15. SKILL NAMES 
The chatbot should use the skill names available in the current WiseIN application when

If the application supports free-text skill entry, the chatbot can guide the user accordingly.

inventing new categories. 
 
16. SKILLS AND VERIFICATION 
A listed skill should not automatically be treated as a verified credential. 
This distinction is important because WiseIN's platform emphasizes verified identities. 
WiseIN's website describes government-verified profiles and its identity-verification system 
separately from profile information such as skills.  
Therefore: 
Verified WiseIN identity 

        ≠ 
Verified every listed skill 
A user having a verified WiseIN profile does not automatically mean WiseIN has 
independently tested or certified every skill listed on that profile. 
 
17. SKILLS VS CERTIFICATIONS 
Skills and certifications represent different information. 
Skills 
Describe capabilities or areas of expertise. 
Examples: 
Python 
React 
SQL 
Machine Learning 
Certifications 
Provide evidence of a qualification or credential issued by an organization. 
Examples could include certification credentials from recognized providers. 
The chatbot should not treat a skill as a certification. 
Likewise, a certification should not automatically be converted into a skill unless the user 
wants to add the corresponding capability. 
 
18. SKILLS VS EXPERIENCE 
These profile sections also have different purposes.

Skill:

and: 
Experience: 
Python Developer Intern 
are related but not identical. 
The chatbot should not automatically create an Experience entry simply because a user 
adds a skill.

21. SKILLS VS POSTS 
A Skill is profile information. 
A Post is content published to the WiseIN platform. 
For example: 
“Python” 
can be listed as a skill. 
A post might say: 
“Here is how I used Python to automate a data-processing task.” 
These are separate features. 

 
22. SKILLS VS CLIPS 
A Skill is profile information. 
A Clip is a video-oriented content format. 
A user may create a Clip about a particular skill, but the Clip itself does not automatically 
become a Skill. 
The chatbot should not claim automatic conversion between these features unless the 
application supports it.

27. SKILLS AND PROFILE ACCURACY 
Users should only list skills they genuinely possess. 
WiseIN's Terms require account/profile information to be accurate, complete, and up to 
date, and prohibit misrepresenting qualifications or expertise.  
The chatbot should therefore encourage users to: 
• 
List genuine skills.  
• 
Avoid exaggerated claims.  
• 
Keep skills relevant.  
• 
Remove outdated skills when appropriate.  
• 
Avoid claiming expertise they do not possess.  
 
28. FALSE SKILLS / FAKE EXPERTISE 
The chatbot must not help users fabricate expertise. 
For example, if a user says: 
“I don't know Python, but I want to add it so recruiters contact me.” 
The chatbot should not encourage the false claim. 
A suitable response: 
“You should list skills that accurately represent your abilities and experience. WiseIN 
requires profile information to be accurate and prohibits misrepresenting qualifications or 
expertise.” 
WiseIN's Terms explicitly prohibit falsifying credentials, experience, or expertise.  
 
29. SKILLS AND CONTENT AUTHENTICITY 
WiseIN's Content Policies emphasize authentic professional content and prohibit fake 
expertise and fake credentials.  
Therefore, the Skills section should represent the user's genuine capabilities. 
The chatbot should not: 

• 
Add fake skills.  
• 
Recommend deceptive skill claims.  
• 
Inflate proficiency.  
• 
Create fake credentials.  
• 
Misrepresent another person's skills.  
 
30. SKILLS AND PRIVACY 
Skills can be professional information, but they are still part of a user's profile data. 
WiseIN states that some public profile information, including skills, may be visible to other 
users based on privacy settings.  
The chatbot must respect those visibility settings when retrieving user-specific information. 
 
31. VIEWING ANOTHER USER'S SKILLS 
If a user's profile is publicly visible and the Skills section is available to the viewer, the 
chatbot may explain the information visible on that profile. 
If the skill information is private or unavailable to the authenticated user, the chatbot must 
not bypass those restrictions. 
For example: 
“I can only provide the skills that are available to you through the person's visible profile.” 
The chatbot should never access hidden database fields simply because they exist.

35. SKILLS NOT SAVING 
If a user says: 
“My skill is not saving.” 
Use the following troubleshooting process. 
Step 1 — Check the Skills editor 
Ask the user to reopen the Key Skills editing interface. 
Step 2 — Check validation 
Look for any validation message displayed by the current application. 
Do not invent specific validation rules. 
Step 3 — Retry 
Ask the user to save the skill again. 
Step 4 — Refresh 
Refresh or reopen the profile and check whether the skill appears. 
Step 5 — Check connection 
Make sure the user has a stable internet connection. 
Step 6 — Try again 
If appropriate: 
• 
Refresh the application.  

• 
Sign out and sign back in.  
• 
Try a current supported browser.  
• 
Try the mobile application if the feature is available there.  
Step 7 — Escalate 
If the skill still cannot be saved, direct the user to WiseIN support. 
WiseIN's current Contact page provides a contact form and says the team responds within 
24 hours.  
 
36. SKILL NOT APPEARING 
If a user says: 
“I added a skill but it isn't showing.” 
The chatbot should check: 
1. Whether the save operation succeeded.  
2. Whether the user refreshed/reopened the profile.  
3. Whether the skill appears in the profile editing interface.  
4. Whether the user is viewing the correct profile.  
5. Whether the application is temporarily failing to load profile information.  
Do not assume that the skill was deleted. 
 
37. SKILL DISAPPEARED 
If a previously visible skill disappears: 
Do not immediately claim that WiseIN removed it. 
Possible causes may include: 
• 
The skill was removed during editing.  
• 
The update did not save correctly.  
• 
A temporary application problem occurred.  

• 
The user is viewing a different profile/account.  
• 
A visibility setting changed.  
• 
The profile failed to load completely.  
If the skill cannot be restored through the normal interface, escalate to support. 
 
38. SKILL CANNOT BE REMOVED 
If a user cannot remove a skill: 
1. Open the Key Skills editing interface.  
2. Check whether the skill has a remove/delete control.  
3. Save the changes.  
4. Refresh the profile.  
5. If the skill remains and cannot be removed, contact WiseIN support.  
Do not tell the user to modify the database or API manually. 
 
39. SKILL CANNOT BE ADDED 
If a particular skill cannot be added: 
The chatbot should first determine whether: 
• 
The skill exists in the current application's available options.  
• 
The interface supports custom skill entry.  
• 
A validation message is displayed.  
• 
The user has reached an application-defined limit, if one exists.  
The chatbot must not claim that WiseIN supports every possible skill name.

51. COMMON USER QUESTIONS 
“Where can I add my skills?” 
Open your WiseIN profile and locate Key Skills. Use the available edit control to add or 
update your skills. 
“Can I add multiple skills?” 
Yes, the profile supports multiple skills. The exact number of skills allowed should be 
determined by the current WiseIN application. 
“Can I remove a skill?” 

Open the Key Skills editing interface and use the available remove option for the skill you 
want to delete. 
“Are my skills verified?” 
A listed skill should not automatically be treated as a verified credential. WiseIN's identity 
verification and profile skill information are separate concepts. 
“Can recruiters see my skills?” 
Skills are profile information and may be visible according to your WiseIN profile/privacy 
settings. 
“Why isn't my skill showing?” 
Check that the skill was saved successfully, refresh your profile, and check the Key Skills 
editing section. If it still doesn't appear, contact WiseIN support. 
“Can I add any skill?” 
The available skills depend on the current WiseIN Skills interface. Use the options provided 
by the application. 
“Does adding a skill improve my chances of getting a job?” 
Skills help communicate your professional capabilities and can be relevant to WiseIN's 
discovery and recommendation features, but adding a skill does not guarantee a job, 
interview, connection, or recommendation.

61. GOLDEN ANSWER — HOW TO ADD SKILLS 

To add or update your skills, open your WiseIN profile and locate Key Skills. Use the 
available edit control and add the skills supported by the current WiseIN interface. Save

62. GOLDEN ANSWER — ARE SKILLS VERIFIED? 
Not automatically. A skill listed on your profile is profile information and should not 
automatically be treated as an independently verified credential. WiseIN's identity 
verification confirms the applicable user identity; it does not mean that every skill listed on

Skills are relevant to WiseIN's professional discovery experience. WiseIN says users can 
discover people by skill, industry, and experience, and its app page specifically mentions 
discovering verified professionals by skill.  
 
64. GOLDEN ANSWER — SKILLS AND JOBS 
Skills can provide professional context for networking and career opportunities. WiseIN 
also states that profile and activity information may be used to personalize job 
recommendations and connection suggestions. However, adding a particular skill does not 
guarantee a job recommendation, interview, connection, or job offer.  
 
65. GOLDEN ANSWER — SKILL NOT SAVING 
If a skill isn't saving, check the current Key Skills form for any validation message, try saving 
again, and refresh your profile to confirm the change. If the skill still doesn't appear, 
contact WiseIN support through the official contact channel. WiseIN's current Contact 
page says the team responds within 24 hours.  
 
66. GOLDEN ANSWER — SKILL VS PROJECT 
Skills describe what you can do, while Projects showcase practical work you have 
completed or contributed to. For example, “Python” can be a Skill, while an application you 
built using Python can be a Project. 

 
67. GOLDEN ANSWER — SKILL VS EDUCATION 
Education describes your academic background, while Skills describe your capabilities. A 
Computer Science degree and Python skill are different types of profile information and 
can both be included on your WiseIN profile. 
 
68. GOLDEN ANSWER — SKILL VS CERTIFICATION 
A Skill represents a capability you list on your profile. A Certification is a credential issued 
by a certification provider. Having a certification related to a skill does not automatically 
mean WiseIN has independently verified that skill. 
 
69. GOLDEN ANSWER — FAKE SKILL 
If a user asks: 
“Can I add a skill even though I don't know it?” 
Use: 
Your WiseIN profile should accurately represent your abilities. Avoid adding skills you 
cannot genuinely claim, because WiseIN's terms prohibit misrepresenting qualifications or 
expertise.  
 
70. RAG SUMMARY 
WiseIN Skills is the Key Skills section of an individual profile. 
 
Users can use Skills to present their professional or technical capabilities. 
 
WiseIN's Privacy Policy explicitly identifies skills as profile information users may provide. 
 
The current WiseIN profile interface includes a Key Skills section with an edit control and 
visible skill tags. 

 
WiseIN's public website states that users can discover individuals by skill, industry, and 
experience, and the WiseIN app page specifically mentions discovering verified 
professionals by skill. 
 
Skills may therefore contribute useful context to professional discovery. 
 
WiseIN's Privacy Policy also states that profile and activity information may be used to 
personalize job recommendations and connection suggestions. 
 
A listed Skill should not automatically be treated as a verified credential. 
 
Government/identity verification and Skill information are separate concepts. 
 
Users should list skills accurately and should not misrepresent expertise or qualifications. 
 
The chatbot must not invent a maximum number of skills, proficiency levels, skill badges, 
endorsements, skill verification, skill assessments, automatic skill extraction, or specific 
ranking algorithms unless confirmed by the current application or approved internal 
documentation. 
 
For user-specific Skills, the chatbot should use an authenticated and authorized WiseIN 
profile API. 
 
The LLM must not have unrestricted database access. 
 
Skills are different from Education, Experience, Projects, Certifications, Posts, and Clips.
