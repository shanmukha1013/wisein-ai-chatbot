24. Messaging 
✦ MESSAGING 
WiseIN messaging allows users to communicate directly with people in their network. Users can 
start conversations with connections and communicate through private messages. 
Messaging is designed for professional communication, networking, collaboration, and 
relationship building between verified WiseIN users. 
 
✦ Purpose of Messaging 
The messaging feature allows users to: 
●​ Communicate privately with other WiseIN users 
●​ Continue conversations with people they are connected with 
●​ Discuss professional opportunities 
●​ Share information and ideas 
●​ Build professional relationships 
●​ Communicate after connecting with another user 
 
1. Accessing Messaging 
Users can access messaging through the Chat section in the main WiseIN navigation. 
The left navigation includes: 
●​ Home 
●​ Explore 
●​ Waves 
●​ Jobs 
●​ My Network 
●​ Chat 
●​ Meetings 
●​ Analytics 
●​ Organizations 

●​ Settings 
Selecting Chat takes the user to the messaging area. 
 
2. Starting a Conversation 
A user can start a conversation with another user through available Message actions. 
For example, in My Network, users who are already connected can have a Message button 
next to their profile. 
Basic flow 
My Network → Following/Connections → Select User → Message 
The user can select Message to begin or continue communication with that person. 
 
3. Messaging With Connections 
Messaging is connected with the user's network. 
When users are connected with another person, the interface can provide a Message option for 
that person. 
For example, the My Network interface displays connected users with a Message button. 
The conversation can then be continued through the Chat/Messaging section. 
 
4. Conversation List 
The Chat section is used to manage conversations. 
A conversation list can contain users with whom the current user has previously communicated. 
Each conversation represents a private communication thread between users. 

Typical conversation information may include: 
●​ User profile 
●​ Name 
●​ Latest message 
●​ Conversation status 
●​ Message activity 
Knowledge-base note: The exact conversation-list fields and ordering should be 
verified against the current WiseIN Chat interface. 
 
5. Opening a Conversation 
To communicate with someone: 
1.​ Open Chat. 
2.​ Locate the required conversation. 
3.​ Select the conversation. 
4.​ View the previous messages. 
5.​ Type a new message. 
6.​ Send the message. 
The conversation remains available so users can continue communicating later. 
 
6. Sending Messages 
Inside a conversation, the user can enter their message in the message input area. 
General flow 
Open Conversation → Type Message → Send 
The message should appear in the conversation after it has been successfully sent. 
If the message fails to send, the user should retry and, if the issue continues, report the problem 
through Customer Support. 
 

7. Receiving Messages 
When another WiseIN user sends a message, the conversation becomes available in the user's 
messaging area. 
The user can: 
1.​ Open Chat. 
2.​ Select the conversation. 
3.​ Read the received message. 
4.​ Reply to the user. 
New-message notifications may also be available depending on the user's notification settings. 
 
8. Continuing Existing Conversations 
Users do not need to create a new conversation every time they want to communicate with 
someone. 
An existing conversation can be opened from Chat and continued by sending another message. 
This allows users to maintain an ongoing professional conversation. 
 
9. Messaging From My Network 
The My Network section provides several relationship categories, including: 
●​ Conversations 
●​ Follow Request 
●​ Request Sent 
●​ Following 
●​ Followers 
When a user is already connected/followed, the interface can display a Message button. 
For example, the My Network screen shows connected users such as: 
●​ Project Coordinator 

●​ Founder 
●​ Other professional users 
with a Message action. 
This allows users to move from networking to direct communication. 
 
10. Professional Communication 
WiseIN is designed as a professional networking platform. 
Users should use messaging for meaningful communication such as: 
●​ Professional networking 
●​ Collaboration 
●​ Job-related communication 
●​ Business discussions 
●​ Project discussions 
●​ Career discussions 
●​ Knowledge sharing 
●​ Introductions 
●​ Follow-ups 
Users should communicate respectfully and avoid unnecessary or repetitive messages. 
 
11. Messaging and Privacy 
Messages are private communications between the participants of the conversation. 
Users should not share another person's private messages publicly without appropriate 
permission. 
This is consistent with WiseIN's Content Policies, which state that private conversations and 
screenshots of DMs should not be publicly posted without consent from everyone involved. 
 

12. Unwanted Messages 
If a user receives inappropriate, unwanted, abusive, fraudulent, or otherwise problematic 
messages, they should use the available reporting or blocking mechanisms where applicable. 
Users should not use messaging to: 
●​ Harass another user 
●​ Send scams 
●​ Send fraudulent offers 
●​ Repeatedly spam users 
●​ Request sensitive personal information unnecessarily 
●​ Send threatening messages 
●​ Share malicious or inappropriate content 
Serious violations may result in account restrictions, suspension, or permanent account action 
according to WiseIN's policies. 
 
13. Blocking a User 
WiseIN provides a Blocked section under Settings. 
If a user needs to prevent interaction with another account, they can use the available blocking 
functionality. 
Navigation 
Settings → Blocked 
Knowledge-base note: The exact effect of blocking on existing conversations, 
message delivery, and previous messages should be verified from the current 
implementation before the AI gives a definitive answer. 
 
14. Messaging Notifications 
Users may receive notifications related to messaging activity. 
Notification preferences can be managed through: 

Settings → Notifications 
If a user is not receiving expected message notifications, the AI assistant should first guide them 
to check their notification settings. 
 
15. Message Delivery Problems 
If a message cannot be sent, the user should check: 
1.​ Internet connection. 
2.​ Whether the Chat page is loading correctly. 
3.​ Whether the conversation is still available. 
4.​ Whether the page needs to be refreshed. 
5.​ Whether the problem occurs with one user or multiple conversations. 
If the problem continues, the user should report it to WiseIN Customer Support. 
 
16. Messaging Troubleshooting 
Problem: Message is not sending 
Possible checks: 
●​ Check internet connection. 
●​ Refresh WiseIN. 
●​ Reopen the conversation. 
●​ Try sending the message again. 
●​ Check whether the issue occurs with other conversations. 
If the problem continues, contact Customer Support. 
 
Problem: Chat is not loading 
Possible checks: 
●​ Refresh the page. 
●​ Check the internet connection. 

●​ Log out and log in again. 
●​ Try accessing WiseIN again. 
If the issue continues, report the problem. 
 
Problem: I cannot find a conversation 
Check the Chat section and search for the relevant user/conversation if search functionality is 
available. 
If the conversation still cannot be found, contact Customer Support. 
Knowledge-base note: Search behavior should be verified before the AI gives 
step-by-step instructions. 
 
Problem: I am not receiving message notifications 
Go to: 
Settings → Notifications 
Check whether relevant notification settings are enabled.

18. Messaging vs Meetings 
Messaging and Meetings serve different purposes. 
Messaging 
Used for asynchronous communication through messages. 
Meetings 
Used for scheduled or live communication through WiseIN's meeting functionality. 
A user may use messaging to communicate before or after a meeting. 
 
19. Messaging Safety 
Users should never share sensitive information unnecessarily through messages. 
Avoid sharing: 
●​ Passwords 
●​ OTPs 
●​ Authentication codes 
●​ Financial credentials 
●​ Private identity documents 
●​ Other people's personal information 
If another user asks for suspicious information or money, the user should treat it as potentially 
unsafe and report the account or message where appropriate. 
 
20. AI Assistant Handling of Messaging 
Questions 

The WiseIN AI Assistant should help users with general messaging-related questions. 
Example questions 
User: "How do I message someone?" 
AI:​
 "Open My Network and find the person you want to communicate with. If the Message option is 
available, select it to start or continue the conversation." 
 
User: "Where can I find my messages?" 
AI:​
 "Open the Chat section from the left navigation menu. Your available conversations can be 
accessed there." 
 
User: "I'm not getting message notifications." 
AI:​
 "Please open Settings → Notifications and check your notification preferences. If notifications 
are enabled but messages still aren't appearing, try refreshing WiseIN. If the issue continues, 
contact Customer Support." 
 
User: "Someone is sending me unwanted messages." 
AI:​
 "If you are receiving inappropriate or unwanted messages, use the available reporting or 
blocking options. You can also contact WiseIN Customer Support if you need additional 
assistance." 
 
21. When AI Should Escalate 
The AI assistant should escalate the issue to human support when: 
●​ Messages consistently fail to send. 
●​ Conversations disappear unexpectedly. 
●​ A user's account appears to have a messaging restriction. 

●​ A serious privacy issue is reported. 
●​ A user reports harassment, threats, scams, or fraud. 
●​ The user reports unauthorized access to their account. 
●​ The problem appears to be a technical bug. 
●​ The AI cannot determine the correct solution from the available WiseIN documentation. 
 
22. Information to Collect for a Messaging 
Bug 
When escalating a messaging-related technical problem, the AI should collect: 
●​ User's WiseIN account information, where appropriate 
●​ Description of the issue 
●​ Name/profile of the affected user 
●​ Steps that caused the issue 
●​ Approximate time the issue occurred 
●​ Screenshot or screen recording, if available 
●​ Error message, if displayed 
●​ Device/platform being used 
●​ Whether the issue happens consistently or intermittently 
The AI should not request passwords, OTPs, authentication codes, or other sensitive 
credentials.

support.
