65. Logout 
Overview 
The Logout option allows a user to securely sign out of their WiseIN account. 
When the user selects Log Out, WiseIN displays a confirmation dialog before completing the 
logout action. 
Location 
Users can access Logout from: 
Settings → Log Out 
Logout Confirmation Dialog 
When the user selects Log Out, a confirmation popup appears. 
Title:​
 Logout from your account? 
Message:​
 “Are you sure you want to logout from your account?” 
The dialog provides two options: 
●​ Cancel — Closes the confirmation dialog and keeps the user logged in. 
●​ Logout — Confirms the action and logs the user out of the account. 
There is also an X button in the top-right corner of the dialog, which can be used to close the 
popup. 
Logout Flow 
Settings → Log Out → Confirmation Popup 
1.​ User opens Settings. 
2.​ Selects Log Out. 
3.​ WiseIN displays the “Logout from your account?” confirmation popup. 
4.​ User chooses: 
○​ Cancel → remains logged in. 
○​ Logout → proceeds with logout. 

AI Customer Support Knowledge 
User: How do I log out of WiseIN?​
 Bot: Go to Settings → Log Out. WiseIN will ask you to confirm the logout. 
User: What happens when I click Log Out?​
 Bot: A confirmation popup appears asking, “Are you sure you want to logout from your 
account?” You can either cancel or confirm the logout. 
User: I clicked Log Out by mistake.​
 Bot: If the confirmation popup is still open, select Cancel to remain logged in. 
User: Can I cancel logout?​
 Bot: Yes. Select Cancel in the logout confirmation popup. 
User: Does logout delete my account?​
 Bot: No. Logout only signs you out of your account. Account deletion is a separate option 
under Settings → Delete Account.
