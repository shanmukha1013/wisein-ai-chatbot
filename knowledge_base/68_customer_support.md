68. Customer Support 
Overview 
The Customer Support section provides users with a direct way to contact the WiseIN support 
team for questions, ideas, bug reports, partnerships, feedback, and other issues. 
WiseIN states that support requests receive a response within 24 hours, usually faster. 
 
1. Contact Support 
Page Heading 
Get in touch

WiseIN invites users to contact the team for: 
●​ Questions 
●​ Ideas 
●​ General inquiries 
●​ Support issues 
●​ Feedback

3. What Happens Next 
WiseIN describes the support process in four steps. 
Step 1 — You send this 
The user submits the support form. 
WiseIN states that submitting the request takes less than 10 seconds. 
Step 2 — Our team reads it 
The WiseIN team reviews the submitted request. 

The page states that this happens within a few hours. 
Step 3 — You get a real reply 
The user receives a response from the support team. 
WiseIN states that users receive a reply within 24 hours. 
Step 4 — No templates. No bots. 
WiseIN states that the response comes from a real human rather than an automated response.

7. AI Customer Support Escalation 
For the WiseIN AI customer-support chatbot, this section is particularly important. 
The chatbot should first attempt to resolve a user's question using the WiseIN knowledge base. 
If the chatbot cannot resolve the issue, it should guide the user toward human customer 
support. 
Suggested Escalation Flow 
User asks question → Chatbot searches knowledge base → Provides solution → User 
confirms whether issue is resolved 
If unresolved: 

Chatbot → Collect issue details → Guide user to Customer Support → Human support 
handles the case 
 
8. Information the Chatbot Should Collect 
Before Escalation 
When appropriate, the chatbot can help the user prepare the information needed by support: 
●​ User's name 
●​ Email address 
●​ What the issue is about 
●​ Detailed description of the problem 
●​ Error message, if any 
●​ Steps that caused the problem 
●​ Screenshot/evidence, if available 
This can make it easier for the support team to understand the issue.
